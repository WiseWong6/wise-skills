# 阶段1：需求澄清

**目标：** 在"拆文章/配图"之前，先把用户的真实需求说清楚：**内容是什么、用在什么场景、谁来看、想要字多还是字少**。其它默认值（如尺寸/风格）不打扰用户。

## 你需要问用户的 4 个问题（优先级从高到低）

1. **内容（先给我原文/要点）**：把要配图的内容贴过来（整段/小节/提纲都行）。
   - （可选补一句）你希望读者看完**记住哪一句话/得到什么结论**？
2. **场景（平台判定 → 定比例）**：发到哪个平台/场景？——小红书 / 公众号封面 / 公众号正文 / PPT / 海报打印 / 其他？
   - 用户明说平台 → 直接采用；可从话术推断（如"发小红书"、"做 PPT"）→ 判定后复述确认；未说明 → 主动问这一问。
   - 场景 → 比例映射（定好场景比例就锁死，后续不再问尺寸）：

     | 场景 | 比例 |
     |---|---|
     | 小红书 | 3:4 |
     | 公众号·封面 | 21:9 |
     | 公众号·正文/其他 | 16:9 |
     | 纯 PPT | 16:9 |
     | 海报打印 | 按需询问（如 A4 竖版） |

   - 仍不明确时默认 `16:9` 并告知用户可随时改。
   - 如果多个场景都有：**哪个是主场景**（我优先为它优化比例、字号与密度）？
3. **受众（谁来看）**：小白 / 从业者 / 老板 / 学生…（决定措辞与隐喻）
4. **字多还是字少**：你希望更"少字清爽"还是更"信息密度高"（决定文案压缩强度）

## 第 5 步：风格选择

在收集完 4 个问题后，请用户选择风格（与 SKILL.md 风格 Gallery 一致，共 10 种）：

```
请选择图片风格：

1. cream-paper（奶油纸手绘）- 配图、信息图、概览、框架图（默认推荐）
2. infographic（扁平化科普图）- 概念解释、原理说明、步骤展示
3. handdrawn（方格纸手绘）- 笔记手绘、学习感
4. healing（治愈系插画）- 情绪叙事、场景氛围、治愈感
5. sokamono（描边插画）- 清新文艺、简洁治愈
6. minimalist-sketch（极简手绘笔记）- 细线条手绘、信息图解
7. xhs-cartoon（小红书卡通）- 干货分享、萌系表达
8. editorial（社论全景）- 深度分析、商业场景
9. cream-journal（奶油手账）- 手账风知识卡片、学习笔记（3:4）
10. editorial-paper（社论纸艺）- 责任关系、工作流重构、AI 工作产品（默认 3:4，可按场景扩展横版）

请输入序号或风格名：
```

**记录用户选择的风格**，供后续阶段使用（在阶段4封装提示词时会读取对应风格块）。

## 本阶段输出物

### DoD（Definition of Done：没确认不进阶段2）

- 你复述给用户确认的 1 句话（推荐直接这样说）：
  - **内容主题 + 主场景（含比例）+ 受众 + 字多/字少 + 确认风格 +（我建议的图类型）**
  - 比例由场景判定表确定（小红书 3:4 / 公众号封面 21:9 / 公众号正文及其他 16:9 / PPT 16:9），不单独打扰用户；无法判定时才默认 `16:9` 并告知可改
- 口径对齐（方便后续阶段衔接）：
  - 这里的"字多/字少"就是后续阶段会用到的"文字预算"
  - "图类型"用户不确定没关系：你可以先推荐一个，用户点头即可进入阶段2
  - "确认风格"会传递到阶段4，用于动态读取对应的风格块模板
- 需求小结（不超过 5 条，尽量用口语化而非硬指标）：
  - 例如：`手机近看为主`、`给小白看`、`偏少字清爽`、`希望读者记住：……`、`先做 1 张概览框架图`、`风格：infographic`

## 给用户的参考输入（让他照抄也行）

- 场景：发小红书 / 公众号封面 / 公众号正文 / PPT / 海报打印（多场景时注明主场景）
- 受众：给……看（小白/从业者/老板/学生…）
- 偏好：字少/字多
- 目标：希望读者看完记住……
- 风格：（可选，不填则系统推荐）
