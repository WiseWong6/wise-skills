# 纸上精密图谱（Paper Precision Atlas）

> 风格标识：`paper-precision-atlas`。以用户确认的暖象牙白纸、石墨轨迹、概念结构与可选主题色为视觉基准。

## 核心定义

这是一种“生成式概念研究图”：在统一的暖象牙白纸上，用精密基准线、石墨结构线、密集连续轨迹、关系节点与可选主题色，把输入内容中的概念及其关系转译成可观察、可追踪的结构。

高密度集中在概念结构内部，由线条的方向、疏密、交叉、分叉与汇聚构成；结构之间保留清楚纸面，使复杂信息仍有呼吸感和阅读顺序。材料较多时根据内容自动分页，每页形成一个完整命题。

## 视觉语法

### 纸面

- 全部图谱区域使用同一种暖象牙白细纤维纸，纸色平整、柔和、微微偏暖。
- 纸纹细密均匀，呈现高质量纸本扫描或艺术微喷的真实触感。
- 光线平缓柔和，纸张纹理与细线始终清晰可见。
- 输入中存在明确代表色时，颜色只出现在线条、节点和很小的交点亮光中；其余情况保持石墨灰阶。

### 四层线条

1. **基准层**：极细浅灰中心轴、十字坐标、基准圆、虚线轮廓与对齐标记，建立空间秩序。
2. **结构层**：石墨灰或深墨色的骨架、网格、截面、轮廓与关系曲线，说明概念怎样成立。
3. **密度层**：大量细而连续的黑、灰、银白轨迹在概念结构内部交叠，以线条积累出通透体积，纸面可透过线网。
4. **激活层**：一组连续轨迹沿关键结构与关系路径穿行。输入中存在明确代表色时，代表色用于约 20–35% 的关键轨迹；其余情况使用深浅不同的石墨色完成激活层。

线宽具有清楚层级：基准线最细最浅，结构线清晰稳定，主体密集轨迹最有重量。曲线整体精确、流畅、连续、可追踪，并保留轻微铅笔摩擦、针管笔断续和纸上颗粒。

### 颜色与亮光

- 材料版采用材料明确提供的品牌色、对象颜色或配图主体色；图片版从上方原图主体区域提取最具识别度的一种主色。
- 输入没有明确代表色时，结构线、密度线、关键路径和节点统一使用深浅不同的石墨灰阶。
- 代表色或深石墨色沿关键路径渐进出现，可集中在一个局部、一段关系或一个重要变化阶段。
- 少数轨迹交汇点与关键节点出现同色系或石墨银白的柔和亮光，一两条关键轨迹可以自然延伸为长弧线。
- 亮光紧贴轨迹，范围小而克制，周围纸纹保持清楚可见。

### 概念形成方式

- 每个概念都依据当前输入的含义生成专属结构，由连续曲线的方向、疏密、交叉、遮挡、分叉、汇聚与连接关系形成。
- 密度最高的区域具有明确流向、结构中心、交汇点或变化逻辑。
- 相关概念分别拥有自己的形态、轨迹、节点和内部逻辑，并通过空间关系共同表达本页命题。
- 概念之间的主次、因果、并列、循环、冲突或演化关系，转译为轴线、长弧、共享节点、连续轨迹、距离和尺度差。

### 核心概念与相关概念

- 自动分页版每页围绕一个核心概念，配置 1–3 个与它直接相关的概念。
- 核心概念承担最强视觉重量；相关概念尺寸更小、线条略轻，同时保持完整可辨的结构。
- 概念组自然分布在同一连续纸面上，组与组之间保留明显间距，形成密集区与安静区的节奏。
- 离散节点使用少量实心黑点、空心圆或带轻微金属明暗的小节点，并落在轨迹、坐标或关键交点上。

### 文字

- 信息主要由结构、轨迹和关系呈现。
- 输入内容确实需要时，使用短标题、阶段名、结构名或少量说明，放在轴线、图边或留白处。
- 图中出现的名称、数字、参数、公式与结论均以输入材料为依据。

## 构图原则

版式根据概念之间的主次、因果、循环、并列、冲突或演化关系动态生成。每页有一个清楚的视觉锚点，核心概念可位于最能表达关系的位置，相关概念沿真实逻辑自然分布。

密集轨迹集中在概念结构内部，概念组之间、画面四周与文字周围保留安静纸面。自动分页版每页约保留 35–45% 可见暖象牙白纸面；单页高密度版至少保留 20–30%。大小差、方向变化、线条深浅与留白共同建立阅读顺序。

## 输入与交付方式

### A. 材料输入：自动分页或单页高密度

默认先理解整份材料，再根据主题数量、逻辑层级和解释难度自动决定页数。每页独立输出一张 3:4 竖图，围绕一个核心结构命题组织一个核心概念与 1–3 个直接相关概念。

整组页面先建立叙事顺序，再分别确定每页的核心命题、概念关系、空间结构与必要短标签。各页共享同一种纸色、石墨线条和输入色彩体系；每页的概念结构与激活路径由本页内容决定。

用户明确要求“全部内容一张图”或“单页高密度”时，把全部实质内容组织在一张 3:4 中，合并重复表述、压缩文字，并保留至少 20–30% 可见纸面。

### B. 图片输入：一张 3:4 上下对照图

每张输入图单独生成一张 3:4 竖图。整张图沿水平中线分成两个等高区域，各占 50%：上半部分呈现原图，下半部分把同一主体转译成生成式概念研究图。下半部分以主体结构为视觉锚点，可配置 1–2 个与原物直接相关的小型概念结构。

## 简约纸本变体（技术介绍与视频）

用户选择简约、工匠感或黑白技术视频时采用本变体；它不覆盖其他任务已确认的配色与排版。

- 背景使用平整暖象牙白（可用 `#f2f0e8`），纸纤维细而均匀；主体以石墨黑、暖灰分层。用户指定黑白时，即使参考图存在蓝、绿色，也不引入这些强调色。
- 中文、英文与数字统一使用思源黑体，以 Light（300）为主，最高 Regular（400）；依靠字号、疏密和位置建立层级。避免粗黑标题、手写字体与工业窄体混搭。
- 以纸面留白和细线建立分区，减少无意义外框、卡片阴影和大圆角。作品展示使用直角或极轻微圆角；真实输入框可保留必要圆角。
- 左右安全边距一致，标题、图解与页脚按同一左边界对齐；并列指标采用等宽列和一致间距。充分利用安全区，同时保留结构之间的呼吸空间。
- 过程通过连续轨迹、节点选择、分叉、收束、循环回路表达，避免把流程重新画成一排实心按钮或粗大箭头。轨迹必须对应内容中的真实关系。
- 复杂度集中在局部的精密网格、剖面和通透线网；不堆砌与内容无关的科学符号、公式、装饰图谱。
- 动效按帧驱动，回放与拖动保持一致。上一画面退场后再让新标题出现，避免叠影；素材自身带圆角黑底时先处理裁剪边界，不能只缩小外层圆角。
- 生图适合补充纸纹或精密插画；可编辑文字、数字与图表由排版代码呈现。在 Codex 内生成或编辑位图只允许使用 `image_gen.imagegen`。

```text
图【底图编号】负责生成式结构研究图的主体、轴线、轨迹和纸面；图【原始人物编号】是人物身份依据。保持原始人物的【脸型、五官比例、眉眼、发色、发型轮廓和发束方向】。

服装换成【贴合主题的新服装及材质】，搭配【与主题有关的动作或道具】。人物位于【空白位置】，脚或坐姿落在【具体落点】，高度约为全画面的【25–28%】，作为局部点缀。

人物与主主体、相关概念图、标题、关键轴线和关键激活轨迹保持清楚间距。人物保留原始立体卡通质感，纸上精密图谱仍是画面主体。
```

## 交付检查

- 材料默认按内容自动规划页数；用户明确要求时使用一张 3:4 单页高密度图；图片版为一张 3:4，上下严格各占 50%。
- 自动分页版每页表达一个核心结构命题，并围绕一个核心概念组织 1–3 个相关概念。
- 单页高密度版完整覆盖材料的实质内容，并把重复表述合并、长句压缩为短标签。
- 高密度集中在概念结构内部；自动分页版约保留 35–45% 纸面，单页高密度版至少保留 20–30%。
- 每个概念的形态、轨迹、节点与内部逻辑来自当前输入内容。
- 石墨基准层、结构层、密度层和激活层清楚可分，线条积累出通透体积。
- 输入拥有明确代表色时，将它用于 20–35% 的关键轨迹；输入没有明确代表色时，图谱保持纯石墨灰阶。
- 全部图谱区域保持统一的暖象牙白纸色和清楚纸纹。
- 使用 Wise 个人形象时，核对原始脸与发型、25–28% 的人物占比、明确落点及其与核心结构的间距。
