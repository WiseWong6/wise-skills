# 社论纸艺（Editorial Paper）

> 作者：@歪斯Wise

## 视觉契约

- 默认画幅：**3:4 竖版**；当内容场景明确要求横版时，使用指定横版比例，但不把竖图拉伸或裁切。
- 材料：暖象牙纸、可见纸纤维、手工裁切与微微毛边；通过纸层轻阴影表现层次，不使用塑料高光或真实 3D 渲染。
- 配色：墨蓝黑为骨架，低饱和橄榄绿、砖橙、浅矢车菊蓝为少量强调，整体克制而有社论感。
- 构图：一个人物或工作对象居中；3–5 个责任、协作或工作节点以细黑轨道相连。横版时让轨道沿水平方向展开，主体仍是视觉锚点。
- 印刷感：只使用克制的网版/risograph 颗粒与纸艺重叠边，留白清晰。

## 文案与负面约束

- 只保留一个短标题和极短节点标签；不得补充无关小字或品牌标识。
- 不要摄影写实、光泽材质、卡通贴纸、扁平矢量面板、霓虹渐变、复杂数据仪表盘。
- 关系必须可以一眼读懂：节点、轨道、人物/主体的层级不能互相遮挡。

```text
版面像克制的社论纸艺拼贴：可见切纸边缘、轻微纸层阴影、少量网版印刷颗粒；只放短标题「[标题]」和短标签「[标签列表]」，留白明确。

不要摄影写实、3D 渲染、塑料高光、霓虹渐变、复杂仪表盘、额外小字、品牌标识或水印。
```
