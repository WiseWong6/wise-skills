# 中文报告模板

报告必须直接打印给用户，不要求用户打开 Markdown 文件才能理解结论。

## 必须包含

- 一句话结论：有没有实质清理，是否只是自然波动。
- 为什么卡/热：CPU、内存、压缩、swap/pageout、Top 进程。
- 活动监视器维度：CPU、内存、能耗/发热推断、磁盘总览、网络总览、启动项/后台项。
- 是否建议处理：保留、只观察、确认后清理、深度取证。
- 怎么处理：每个候选的 PID、端口、运行时长、父进程、风险、恢复方式。
- Before/After 证据：关键指标、Top CPU、Top 内存、监听端口、候选变化。
- 安全说明：默认未做高权限取证；未确认前不停止、不禁用、不删除。
- 临时产物：snapshot 路径、cleanup ledger 路径、可选报告路径。

## 结论措辞

- 无清理账本：`本轮只是复测；指标变化可能是自然波动，不能宣称明显优化。`
- 有清理账本：`本轮清理了 N 个已确认用户态进程；下面用 before/after 判断影响。`
- 深度取证未确认：`未做深度取证，结论基于低权限快照。`
