# 平台映射与安全等级

## 安全等级

| 等级 | 含义 | 默认 |
|---|---|---|
| L0 | 只读低权限采样 | 允许 |
| L1 | 解释和建议，不执行 | 允许 |
| L2 | 温和停止用户态临时进程 | 低风险可批量确认 |
| L3 | 深度取证，可能敏感或需权限 | 单独确认 |
| L4 | 禁用、删除、配置变更、强杀 | 默认禁止 |

确认规则：L2 低风险项必须先展示清单、收益、风险和恢复方式，可用 `清理低风险项` 一次确认。L2 高风险、L3、L4 必须单独确认具体动作和目标，例如 `确认停止 PID 12345`。泛泛确认不算授权。

## 信号映射

| 维度 | macOS 默认 | Windows 默认 |
|---|---|---|
| CPU | `top`、`ps`、`uptime` | `Get-Process`、CIM OS 摘要 |
| 内存 | `memory_pressure`、`vm_stat`、swap sysctl | CIM OS 内存、进程工作集 |
| 发热/能耗 | CPU 持续占用、thermal/`pmset` 可用信息 | CPU 持续占用、进程 CPU 时间趋势 |
| 磁盘 | `df`、短 `iostat` | 逻辑磁盘空间摘要 |
| 网络 | 本地监听端口、接口概览 | TCP listen 表、适配器摘要 |
| 启动项 | LaunchAgents/Daemons、brew services、`launchctl list` | 低敏启动项摘要、服务摘要 |

默认报告必须说明：低权限信号不是完整取证；它用于判断是否值得处理和是否需要用户确认更深一步。

隐私默认值：不采集完整进程参数；只采集进程名/可执行名、PID、PPID、运行时长、端口、CPU 和内存。完整命令行属于深度检查，需要用户单独确认。
