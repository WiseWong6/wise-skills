# 程序路径的输入与输出

仅在 SKILL.md 的平台选择确定使用程序路径后执行；非 Codex 默认优先使用宿主自带图片能力。

脚本使用本地 Python 3、Pillow、NumPy；仅这三个运行依赖，缺失时报错，不自动安装。

## 读取输入尺寸

```sh
python3 <技能目录>/scripts/render.py inspect <照片绝对路径> [更多照片路径]
```

尺寸已应用照片方向信息。助手先阅读原图选择记忆点，再写 JSON 配置。脚本不具有语义识别功能。

## 配置示例

```json
{
  "styles": ["puzzle", "ticket"],
  "photos": [
    {
      "path": "/absolute/path/photo.jpg",
      "name": "海边记忆",
      "crop_box": [0, 0, 1500, 1000],
      "fragment_center": [0.5, 0.7]
    }
  ]
}
```

- `photos` 为非空有序数组，顺序决定最终拼接顺序，不自动去重。
- `path` 为现有照片的绝对路径，支持 Pillow 能打开的静态照片格式；动画、多帧输入拒绝。
- `name` 可省略，默认使用文件名；导出时清理斜线和不可见字符，并加独立序号防重名。
- `crop_box` 必填，为方向校正后的原图像素坐标 `[左, 上, 右, 下]`，可使用小数，必须在原图内且宽高比为 3:2。横图最大框的宽为 min(原宽, 原高×1.5)，高为宽/1.5，按记忆点平移。
- `fragment_center` 必填，为下半区裁切照片内的归一化目标中心 `[x,y]`，范围 0～1。该点用于裁片外接框中心，不是原图坐标；来源框靠边时自动整体移入照片。
- `styles` 可省略，默认两套；仅接受 `puzzle`、`ticket`，不允许空数组或重复项。
- 固定画布1800×2400；不支持用户配置单块缩放或任意画幅，以免破坏对应关系。

## 执行

```sh
python3 <技能目录>/scripts/render.py render --config <绝对路径/config.json> --output <当前任务/outputs/记忆碎片摄影海报>
```

成功时输出 JSON，包含 `status: complete`、实际目录和图片数。目标已存在则使用 `-v2`、`-v3` 等新目录，不覆盖。两套各写 `01_名称.png` 至 `NN_名称.png` 和下一序号的 `完整拼接.png`；根目录保存 `制作检查.json`，记录原照校验值、实际裁切/来源框、半透明边缘检查、拼接位置和检查结果。

失败返回非零退出码和中文错误，删除本次隐藏暂存目录，不发布正式目录。输入错误在创建暂存目录前被检查。报告属于当前批次，不复制到技能目录。
