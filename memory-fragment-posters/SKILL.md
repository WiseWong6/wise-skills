# 记忆碎片摄影海报

将用户提供的照片制作成可以精确拼合的海报。默认同时交付拼图版、票根版；每套为 N 张单张海报加 1 张完整拼接图。用户指定一种样式时只制作该样式。

## 授权与边界

- 仅在用户明确点名或主动选择本技能时执行，不因普通图片关键词自动调用。
- 本技能使用专用程序进行原照片裁切、遮罩、纸纹制作与排版，须遵守当前宿主规则及用户授权；若宿主限制程序处理图片，应先解决适用授权，不能以本技能绕过限制。该流程不扩展到其他图片任务，不允许调用任何第三方生图服务。
- 所有摄影内容来自原照片；不调用生成式模型，不重绘、不扩图、不补画、不修复主体、不单独放大片段。照片内的文字、招牌属于摄影内容，不新增文字、标志或装饰。
- 不覆盖原图和既有交付。技能包仅保留作者授权公开的定稿展示素材；不保存后续用户输入照片，也不把照片或任务记录写入个人记忆。示例仅供浏览，制作新任务必须使用该任务的原始照片，不以示例作为输入。

## 工作流程

1. 汇总用户本次提供的照片，保留上传顺序；不扫描无关照片。用可用图片查看能力阅读尚未见过的原图，读取方向校正后的尺寸。此处是理解输入，不是截图或成品视觉验收。
2. **自动选取并直接制作，不等待取景确认。** 为每张照片确定一个有辨识度的记忆点，如人物、翼尖、树木分叉、落日或建筑细节。主体含义由助手根据照片判断，脚本只执行精确坐标，不能把居中裁切描述为自动语义识别。
3. 将下半区取景设为原图内最大的 3:2 横幅框，并沿可移动方向平移，使主体尽量完整。竖图无法同时保留全部环境时优先记忆点；不得通过拉伸或补画解决。确定碎片中心在该取景内的位置，允许细节局部，不为了容纳整个主体放大片段。
4. 先规划整批边界，再裁片。两套版本共用照片取景和目标中心，但轮廓不同。每张海报上半区的碎片、下半区原位填白、最终拼接，必须复用同一份裁片与遮罩，最终只平移、不旋转、不缩放。
5. 在当前任务 `work/` 保存输入配置，按 [输入说明](references/input.md) 填写绝对路径、像素裁切框、碎片中心与样式。禁止将本次私人路径写入技能自身。渲染前检查依赖：Python 3、Pillow、NumPy；缺少依赖时报告缺项，不自行安装。
6. 执行技能目录下 `scripts/render.py render --config <配置绝对路径> --output <当前任务/outputs/记忆碎片摄影海报>`。渲染器自动选择不覆盖的版本目录；只有全部文件验证通过才从隐藏临时目录发布正式成果。
7. 读取返回结果与 `制作检查.json`。只有状态为 `complete` 才报告完成。交付实际输出路径、文件数和检查结果；说明竖图有自然裁切。默认不截图、不启动服务、不额外进行耗时视觉验收。

## 固定设计

- 海报 1800×2400 像素，严格 3:4；上下区域各 1200 像素，直接衔接，无分割线、缝隙或渐变。
- 上半区暖象牙天然纤维纸、轻微颗粒、大面积留白，碎片按外接框居中。下半区原照等比裁切铺满，照片只统一采样一次；不加低饱和滤镜，不改变摄影颜色。
- 拼图版为圆形凸榫和互补凹槽，基础单元 390×390；票根版为互补齿孔，基础单元 420×320，外围齿孔向内。
- 列数为 ceil(sqrt(N))，逐行排列，末行按整数列居中，奇数余量向右留多一列。所有单元连通，没有内部空洞；无相邻单元的边属于外轮廓。
- 提取前统一调整整套单元尺寸，使最终组合不超过画布宽度的 70%、高度的 60%；不得在最终拼接时再缩放。一个照片的最终拼接图仍复用原尺寸单块。
- 无新增文字、Logo、水印、贴纸、胶带、邮戳、厚重阴影、撕纸或额外装饰。

## 检查与故障处理

- 渲染器必须检查保存文件的尺寸、上下区域、所有裁片像素、缺口坐标、轮廓与半透明边缘，以及最终拼接的加权像素和不透明内区。
- 遮罩必须互补、每像素总覆盖量为 255；整体连通且无内部空洞。票根外轮廓齿孔属于外部纸面，不应误判为拼接缝。
- 路径缺失、图像损坏、裁切越界或比例错误、配置含非有限数、尺寸太小以致无法制作有效齿孔时明确停止，不静默跳图或更换来源。
- 主体靠边时整体平移碎片来源框使其位于照片内，并在检查记录中保存实际中心与偏移；上方、缺口和最终图仍必须使用调整后的同一裁片。
- 不把检查失败的临时图片作为交付，不修改之前成功的批次。

调用例子：`用 $memory-fragment-posters 处理这些照片，生成拼图版和票根版。`

依赖：`Python 3 + Pillow + NumPy`；无需网络、模型接口或密钥。测试：`python3 <技能目录>/scripts/test_render.py`。
