# Wise Skills User Release

This directory is a clean user release of Wise Skills. Each named subdirectory is an independently installable Skill payload containing the runtime instructions, scripts, references, assets, and license needed by that Skill.

Included Skills:

- `blue-poster`
- `doubao-tts`
- `image-to-pages`
- `mac-cleanup`
- `optimize-system-performance`
- `ppt-component-atlas`
- `ppt-speech-creator`
- `prompt-creator`
- `prompt-optimizer`
- `skill-optimizer`
- `wise-image-flow`

Install one Skill by copying its directory into the discovery directory used by your Agent, such as `~/.codex/skills/` or `~/.claude/skills/`.

Repository documentation and examples: <https://github.com/WiseWong6/wise-skills>
