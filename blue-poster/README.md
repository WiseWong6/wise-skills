# Blue Poster · 蓝色光波

将一张原图转换为完整的 3:4 光学实验版画海报。Skill 会根据主体结构、透视、材质、氛围与留白，从 `S01–S11` 中选择一个视觉程序；默认生成完整全图，也支持用户明确要求的上下 1:1 对照版。

在 Codex 中使用：

```text
$blue-poster
把这张图做成完整 3:4 蓝色光波海报；风格由你根据原图语义选择。
```
