# 中文报告模板

报告必须直接打印给用户，不要求用户打开 Markdown 文件才能理解结论。

## 必须包含

- 一句话结论：有没有实质清理，是否只是自然波动。
- 为什么卡/热：CPU、内存、压缩、swap/pageout、Top 进程。
- 活动监视器维度：CPU、内存、能耗/发热推断、磁盘总览、网络总览、启动项/后台项。
- 是否建议处理：低风险可批量清理、只观察、高风险需单独确认、深度取证需单独确认。
- 怎么处理：每个候选的 PID、端口、运行时长、父进程、可能收益、风险、恢复方式。
- 决策权：明确说明代理只给证据和建议；用户可以简单选择 `清理低风险项` 或 `只观察`，高风险目标再单独确认。
- Before/After 证据：关键指标、Top CPU、Top 内存、监听端口、候选变化。
- 安全说明：默认未做高权限取证；未确认前不停止、不禁用、不删除。macOS 深度取证必须先做命令路径预检，避免 Python/Homebrew/第三方命令覆盖系统工具。
- 隐私说明：默认不采集完整进程参数，只用进程名/PID/父进程/运行时长/端口/CPU/内存做判断。
- 临时产物：snapshot 路径、cleanup ledger 路径、可选报告路径。
- 危险动作门槛：低风险用户态临时进程可以在列清楚 PID 后批量确认；禁用启动项、改服务/计划任务、改注册表/plist/config、删文件/缓存、强杀、Docker/浏览器/IDE 清理、深度取证、高风险进程停止，都必须单独确认。

## 结论措辞

- 无清理账本：`本轮只是复测；指标变化可能是自然波动，不能宣称明显优化。`
- 有清理账本：`本轮清理了 N 个已确认用户态进程；下面用 before/after 判断影响。`
- 深度取证未确认：`未做深度取证，结论基于低权限快照。`
- macOS 路径冲突：`sample/spindump 属于深度取证；sample 必须使用 /usr/bin/sample，spindump 必须使用 /usr/sbin/spindump。若裸 sample 报 Python 错误，说明是 PATH 阴影，不是 macOS 原生工具坏了。`
- 隐私提示：`默认未采集完整进程参数；如果要看完整命令行，需要你单独确认，因为可能暴露 token、路径或业务信息。`
- 决策提示：`最简单的选择：回复“清理低风险项”或“只观察”。高风险项不会混进批量清理。`
- 确认门槛：`“清理低风险项”只处理报告中列出的低风险 PID；高风险、深度取证、启动项、服务、删除和强杀需要单独确认。`
