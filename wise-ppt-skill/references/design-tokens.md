# 纸墨线稿 · 设计标准（Design Tokens）

> 本标准从《Agent Infra 第一课 · Trace》20 页成品分镜（`trace/video/frames/`）逐页提炼。
> 所有数值都是实测值，不是感觉值。写新页时优先查本文件，不要重新发明。

## 一、背景色

### 1.1 底色体系（单色纸墨，无彩色）

| 角色 | 变量 | 值 | 用途 |
|---|---|---|---|
| 纸底 | `--paper` | `#DFE0D9` | 舞台底色，冷调灰白纸（不是暖米色，不是纯白） |
| 纸底深档 | `--paper-deep` | `#D4D5CD` | 凹陷区、次要面板底 |
| 墨 | `--ink` | `#191917` | 全部线条与文字的唯一颜色 |
| 墨 80% | — | `rgba(25,25,23,.8)` | 主轮廓线（卡片外框、主要图形轮廓） |
| 墨 70% | `--ink-70` | `rgba(25,25,23,.7)` | 强调正文、次级文字 |
| 墨 45% | `--ink-45` | `rgba(25,25,23,.45)` | 档案角注、图题、辅助说明 |
| 墨 25% | `--ink-25` | `rgba(25,25,23,.25)` | 细线框、分隔线 |
| 墨 12% | `--ink-12` | `rgba(25,25,23,.12)` | 构造线、背景格线 |

**硬规则**：整份 deck 不允许出现彩色。强调靠线宽、字重、字族、虚实表达，不靠颜色。

### 1.2 面板填充

- 唯一允许的填充：`rgba(255,255,255,.22)`（柔白，比纸底亮一档）。
- 禁用：纯白 `#fff`（太跳）、灰色填充（发暗发脏）、彩色色块、渐变、阴影堆叠。
- 纸张投感允许极轻偏移影：`box-shadow: 8px 10px 0 rgba(25,25,23,.04)`（仅限"标本贴纸"场景，每页至多一处）。

### 1.3 纸面质感（必选，缺了就不像纸）

1. **纸纹噪点**：SVG `feTurbulence`（fractalNoise, baseFrequency 0.85, 2 octaves），`mix-blend-mode: multiply`，**alpha 0.05–0.08**，铺满舞台，z-index 在内容之上、`pointer-events: none`。已内置在 `shared.css` 的 `.stage::before`。打印需保留色彩准确（`print-color-adjust: exact`）。
2. **两侧档案格线**：左右各一条 1px 竖线，距边 64px，`--ink-12`，opacity .5。已内置在 `.stage::after`。

### 1.3.1 手工质地（每页至多选一种，克制）

"不完美的有机痕迹"是高级感来源，允许但限量：

- **木刻式粗墨线**：3–6px 粗粝笔触 + 颗粒边缘（木刻/印章感），仅作全页唯一质感对比，每页 ≤1 处。
- **压印式极细放射线**：0.5px 放射/同心细线（emboss 感），适合圆形主角的冠冕。
- **颗粒 dust**：`particles.js dust`，alpha ≤.15，避开文字区，每页 ≤2 处。
- **字符即图形**：mono 字符流（`0/1/*/-/.`）以密度构成图形本体（ASCII 明暗），用 `particles.js textPoints` 采样重绘——标准手法，不限于尾卡。
- **构造线不擦除**：辅助圆、虚线基准、作图痕迹全部保留（铜版画测绘感）；精密细线可以画任何具象物（仪器/建筑/生物），不限于抽象图表。

### 1.3.2 装饰件（允许但克制，不喧宾夺主）

极细 1px 线、十字准星 `+`、角落编号系统（页码/索引）、底部一排 mono 刻度数字（贴底边、墨 45%）可作为构图件；**微型 mono 档案字**（10–12px、uppercase、字距 .3em+）贴边缘排布（右上注释块/左下段落/底部刻度排），每页 ≤2 处。

### 1.4 主题开关（URL 参数，由 `stageFit()` 识别）

| 参数 | 效果 | 使用场景 |
|---|---|---|
| （默认） | 暖纸 #DFE0D9 + 墨 #191917 | 一切页面的默认 |
| `?cool` | 冷白 #EDF0EE + 墨 #181C1E + 蓝图青 #1D5C9E 唯一强调色 | 备选冷调实验室风，整份 deck 要么不用要么全用 |
| `?mono` | 纸底不变，强制单色 | 显式声明单色时的等价写法 |
| `?ppt` | 显示左下 `.folio` 页码+署名 | 全屏放映模式；画板/编辑模式不带 |

## 二、字体与字重

### 2.0 Font Mixing（衬线 × 无衬线混排原则）

- **Titles / Quotes / Big Statement → 衬线气质族**：体现社论权威感与"出版物气质"。本体系内由两族承担：**思源宋体 Medium**（statement 大字、落版标题、提问符号）、**霞鹜文楷大字**（引用/金句，衬线笔触）。
- **Body / Data / UI / Labels → 无衬线族**：确保屏幕易读与信息密度可控。本体系内由两族承担：**思源黑体**（正文/说明/标签）、**Courier Prime**（数据/编号/字段码）。
- 同页混排是常态：大字衬线气质 + 正文无衬线，靠字族拉开层级，不靠颜色。

### 2.1 四族字体（全部开源可商用，本地 `@font-face` 加载，分工不重叠）

| 族 | 字体文件 | CSS 变量 | 字重 | 职责 | 禁令 |
|---|---|---|---|---|---|
| 大字族 | 思源宋体 Medium SourceHanSerifCN | `--serif` | 500 | 大字标题、金句、结论、大数字、提问符号 | 全 deck ≤3 页用大字；不用于正文 |
| 正文族 | 思源黑体 Light / Regular | `--sans` | 300 / 400 | 正文、说明、卡题、标签、caption | 16px 以下小字禁用 300（太细不可读） |
| 档案族 | Courier Prime | `--mono` | 400 | 编号、图题、字段码、刻度、坐标、页脚 | 不承担长句叙述 |
| 手写族 | 霞鹜文楷 LXGWWenKai | `--brush` | 400 | 手写批注、圈错 | 全 deck ≤3 处，只圈错处 |

字重纪律：**越大越轻，越小越实**。大字只用思源宋体 Medium 500（衬线字形本身已具出版物分量，Medium 比 Bold 更文气、与纸墨克制气质契合）；正文默认 300；需要强调时升 400，而不是加颜色。

### 2.2 字号阶梯（1920×1080 舞台坐标系）

| 层级 | 字号 | 字体/字重 | 用途 |
|---|---|---|---|
| giant | 76px（上限 96） | 思源宋体 Medium | 金句、落版大字 |
| h1 | 60px | 思源宋体 Medium | 页面主标题（statement 页） |
| h2 | 40px | 思源宋体 Medium | 次级大字、提问符号 |
| caption | 32–36px（基准 33–34） | 思源黑体 **400** | 底部一句结论 |
| 卡题/栏题 | 24–26px | 思源黑体 400 | 卡片标题、栏目标题 |
| 正文/说明 | 18–22px | 思源黑体 300 | 条目、字段说明、气泡文字 |
| 字段码/数据 | 13–20px | Courier Prime | INPUT/LATENCY 等字段码、数字 |
| 图题 FIG. | 15px | Courier Prime + 字距 .3em | 图版编号 |
| 角注/页脚 | 13px | Courier Prime + 字距 .22em | doc 角注、folio、时间码 |

### 2.3 档案族排版细节

- 英文一律 `text-transform: uppercase` + `letter-spacing: .22–.3em`。
- 字距用 `text-indent` 补偿保持视觉居中（居中 mono 文字加等宽 text-indent）。
- 中文原则上不进 mono（Courier Prime 无中文字形，走 per-glyph fallback）：**mono EN + 中文短注混排可接受**（如 `w ≈ 0.91 · 它看见的`），但中文长句、大字号中文禁用 mono（fallback 破坏灰度）。

## 三、线宽与图形语言

### 3.1 线宽规约（全套统一，以样本 S09 档位为基准）

| 线型 | 宽度 | 颜色 | 用途 |
|---|---|---|---|
| 主轮廓 | 1.2–1.4px | 墨 80% | 卡片外框、主要图形轮廓、面板 |
| 内框线 | 0.6px | 墨 35% | 双线卡框的内圈（内缩 4–5px） |
| 分隔线 | 0.8–1px | 墨 50% | 卡内分隔、栏间分隔 |
| 构造线 | 0.5–0.7px | 墨 25–45%，虚线 `3 5` 或 `2 6` | 十字基准、象限轴、引线 |
| 强调线 | 1.8–2.2px | 墨 100% | 权重最高的一条（弧/流/主线），每页至多一处；**符号笔触（✓/✗/手写符号，3–3.5px 短 path）不计入此限** |
| 剖面填充 | 0.7px 45° 斜线，间距 5–9px | 墨 35% | hatch pattern，表实体/投影/选中 |

### 3.2 双线卡框（全套通用卡片件）

外框 1.2–1.4px @ 墨 80% + 内框 0.6px @ 墨 35%、四边内缩 4–5px。卡片内部标配：编号/短横 → mono EN 角标 → 中文卡题（400/24px）→ 分隔线 → 圆点字段行（中文 300/19–21px + 右侧 mono 13px 字段码）。

### 3.3 节点与连接件

- 落点：双圈 + 实心核（外圈 1.2px + 内圈 0.6px + r2.4 实心点）。
- 箭头：细线开放箭头（两条 1.2–1.4px 线段成角），禁用实心三角箭头。
- 引线：0.7px 虚线 + 中点 2.4px 小圆点。
- 刻度：主齿 1px、副齿 0.5px，配合 mono 数字——时间轴、圆环、尺子共用。
- 尺寸标注：端点短刻度 + 虚线引上线 + mono 数字（如 `50 m`、`280 PX`）。

### 3.4 手绘批注族（每处都是"人"的痕迹，限量使用）

- 旋转 ±3–5° 的椭圆圈（两笔叠出：第二笔 opacity .45–.55、反向旋转）。
- 霞鹜文楷手写文字，可整体旋转 -1.5–-3°。
- 断口表达"缺失/错误"：纸色 rect 擦除 + ✕ 两笔细线，或虚线 + 撕裂毛边。

### 3.5 粒子语言（particles.js，= 画面的质地而非装饰）

| 函数 | 语义 | 用法 |
|---|---|---|
| `cluster` | 高斯点簇：token/节点的物质感 | 主角形态 |
| `dust` | 氛围尘埃，alpha ≤ .15 | 避开文字区，每页至多 2 处 |
| `arc` / `brokenArc` | 点流弧 / 断弧散落 | 连接与断裂的叙事 |
| `textPoints` | 文字轮廓采样 → 粒子重绘 | 尾卡大字、粒子海报 |

规则：粒子是"密度与秩序"的语言——秩序网格=正确/结构，缺粒坠落=错误/异常。**不是每页都要用**，叙事图版页（卡片/流水线/时间轴）不用粒子。

### 3.6 自由 SVG 绘制规约（语义图形语言）

上位原则只有一条：**图形必须携带语义，装饰性重复不是图形。** 画任何元素前先问"它的形状说出了什么"。

**① 线型即语义（固定映射，全 deck 一致）**

| 线型/手法 | 语义 |
|---|---|
| 实线 → 虚线 → 疏虚线（渐虚） | 粒度拉远 / 确定性递减 / 不可见过程 |
| 线宽三档（0.6 / 1.1 / 1.4+） | 权重、主次、流量大小 |
| 虚线容器（圆角/直角逐区） | 系统边界、责任域、旁路（不并入主流程） |
| 断口 + ✕（纸色擦除） | 否决、缺失、错误、不并入 |
| hatch 剖面 | 实体、拦截物、选中、投影 |
| 双圈+实心核 | 落点、站位、标本钉 |
| 回环弧箭头 | 闭环、迭代、反馈（弧上必须挂语义标签） |
| 肘形引线（先横后斜，单调不交叉） | 图中元素 → 边缘标签栏的归属 |

**② 共享坐标系**：多行/多段内容共用一条刻度尺 + 虚线栅格（尺子在上或下，mono 数字），元素以"标本钉"落刻度——禁止每行各自为政的平行元素。

**③ 仪器化图元**：流程/步骤页的每段图元必须形态各异（单据纸/甘特条带/刻度表盘/报告卡/芯片组），像一排不同的仪器；图元 200–600px，不做框内小图标。

**④ 构造线不擦除**：辅助圆、虚线基准、作图痕迹保留（铜版画测绘感）；十字准星 `+` 做套准标记。

**⑤ 复合骨架三件套**（战略框架页用）：顶部阶段链 → 中部维度矩阵（左竖排维度栏 × 右列区）→ 底部 chevron 收束条；层间用细线分隔，信息密度最高页型，数据仍全部自编。

**⑥ 反馈回路**：主链之外的双向/返回关系用虚线弧 + 弧上标签（mono 小字），不从主链节点直接横穿画面。

**⑦ 禁区**：同构矩形阵列（同款框 ≥3 充当主体）、框内小图标充当图元、实心三角箭头、为填满而加装饰。

## 四、留白与画面组织

### 4.1 舞台与骨架

- 固定舞台 **1920×1080**，`.stage` 相对定位、`overflow: hidden`；`stageFit()` 按 `min(vw/1920, vh/1080)` 等比缩放居中。
- **一页一个 HTML 文件**（`frames/shot-NN.html`），页与页之间不共享运行时状态。

### 4.2 固定件三件套（每页必备）

1. **左上档案角注 `.doc.tl`**：top 44 / left 48，mono 13px、字距 .22em、行高 2.1、墨 45%，两行：`项目 — 章节` / `本页关键词`（英文大写）。
2. **底部居中结论 `.caption`**：`left/right: 0`、`bottom: 100–126`（基准 118）、text-align center、思源黑体 **400**、33–34px、字距 .04em、z-index 5。一句陈述句，句号收尾。尾卡页可无 caption。
3. **左下页脚 `.folio`**：left 48 / bottom 44，mono 13px、字距 .22em、墨 45%，格式 `NN / TOTAL — BY 署名`。**仅 `?ppt` 模式显示**（`:root.ppt .folio { display:block }`）。

### 4.3 图题组件（工程制图页标配）

`FIG. NN — 标题`：mono 15px、字距 .3em、墨 45%，位置 x180–220 / y176–192，下方配 0.6px @ 墨 30% 短横线（长约 260–340）。叙事插画页、UI 写实页可省略。

### 4.4 安全区与留白纪律

- 左右边距：常规 150–220px；满幅 UI 页可收到 100px。
- 内容纵向区间 **y170–880**；caption 上方（y900+）必须留空，不压 caption。
- **一页一个主角**：主角图形占画面 40–70%，居中或中轴 x960 展开；其余全部退让为标注与留白。封面/Outro/金句页留白必须 **>60%**。
- **构图平衡**：多元素构图的视觉重心必须落在中轴 x960 ±10% 内，或左右明确配平（左图右文 / 左文右图）；内容主体带为 y260–840，禁止内容带悬浮在上半页、下半页全空。
- **视觉平衡 65/35**：内容（文字信息）≈65% + 视觉元素（图形/装饰）≈35%；图形化表达优先于表达组件，但图形不淹没信息。
- 信息密度上限：文字块不超过 3 个层级；每页强调线 ≤1 处、大字 ≤1 处、手写批注 ≤1 处。
- 禁止：标题+正文+结论条的传统幻灯片三段式骨架；多主角并列抢视线；**同构矩形阵列**（>3 个同尺寸同结构框排成行/列，无层级无主角）；把留白当"没排满"去填。

### 4.5 节奏策略（整 deck 观感）

- **纯色纪律**：整份 deck 全部纸底 `#DFE0D9`。**禁止整页深色底**（含 `#191917` 及任何低亮度底色）——墨只用于线条与文字，不当底色。
- **节奏靠纸底页型穿插**：每 3–4 张信息硬页插 1 张呼吸页——章节隔页（超大编号+章节名，留白 >60%）、金句页（纸底超大衬线）、粒子海报页或极简图版页。
- **强调手段白名单**（不靠反色）：字级对比、线宽档位、留白比例、双线卡框、主角占比。
- **Flow**：保持 `硬 - 硬 - 呼吸 - 硬` 或 `硬 - 呼吸 - 硬` 穿插，避免连续 4 张以上"信息硬页"。

### 4.6 页面类型四轴（选版式时先归类）

| 类型 | 特征 | 代表页 |
|---|---|---|
| 叙事插画页 | 场景画/标本卡，有故事角色，可配手写批注 | 聊天标本、洗车场景 |
| 工程制图页 | FIG 图题 + 精密细线图版（流水线/时间轴/矩阵/树/漏斗） | 大多数概念页 |
| 粒子海报页 | 粒子密度主角 + 极少文字，情绪页 | 黑匣子、金句、尾卡 |
| UI 写实页 | 产品界面线框 mock，信息密度最高，数据全部自编 | 后台 Trace 列表 |

## 五、两种浏览模式

### 5.1 画板模式（`index.html`）

缩略图总览：3 列网格，每格 16:9 iframe 载入 `frames/shot-NN.html` 按比例缩放，下方 mono 页码 + 中文标题 + 时间码 + 一句话 VO。按幕分组，幕间 mono 分隔条。点击新标签页打开 1920×1080 原尺寸。模板：`assets/board-template.html`。

### 5.2 全屏模式（`deck.html`）

放映视图：全视口 iframe 逐页载入，URL 自动追加 `?ppt`（触发 `.folio` 页脚与页码显示）。翻页：←/→、↑/↓、空格、PageUp/PageDown、触屏左右/上下滑动。右下 mono 页码指示。模板：`assets/deck-template.html`。

两个模式共用同一个 `SHOTS` 配置数组（编号/标题/时间码/VO），由各自模板顶部的配置区填写。

## 六、外部依赖（按需引入，必须纸墨化）

默认零外部依赖（字体全本地）。以下两个 CDN 允许按需解开（`shot-template.html` 里已放注释掉的链接）：

### 6.1 FontAwesome 6（图标）

- CDN：`https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css`
- 强制墨色：`color: var(--ink)` 或墨色阶梯透明度；禁彩色图标、禁动效图标。
- 尺寸克制：≤32px，配合 mono 小标签使用；图标是标注件，不当主角。

### 6.2 ECharts 5（仅复杂数据图表）

- CDN：`https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js`
- 仅在折线/柱状/散点等真实复杂数据图、自绘 SVG 成本过高时启用；能用细线 SVG 画的不用库。
- 权威参考：官网文档 `https://echarts.apache.org`（本地无 echarts 相关 skill）。
- **去色改造（强制）**：实例 `color` 色板全部替换为墨色阶梯（如 `['#191917','rgba(25,25,23,.55)','rgba(25,25,23,.3)']`）；axisLine/splitLine 用 0.6–1px 墨色；去阴影、去渐变、去圆角；文字字体走 `shared.css` 变量（mono/sans）；数据全部自编。
- 改造细则见 `references/components.md` 第四节。
