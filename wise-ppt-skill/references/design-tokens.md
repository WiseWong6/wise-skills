# 纸墨线稿 · 设计标准（Design Tokens）

> 本标准从《Agent Infra 第一课 · Trace》20 页成品分镜（`trace/video/frames/`）逐页提炼。
> 所有数值都是实测值，不是感觉值。写新页时优先查本文件，不要重新发明。

## 一、背景色

### 1.1 底色体系（单色纸墨，无彩色）

| 角色 | 变量 | 值 | 用途 |
|---|---|---|---|
| 纸底 | `--paper` | `#DFE0D9` | 舞台底色，冷调灰白纸（不是暖米色，不是纯白） |
| 纸底深档 | `--paper-deep` | `#D4D5CD` | 凹陷区、次要面板底 |
| 墨 | `--ink` | `#191917` | 全部线条与文字的唯一颜色 |
| 墨 80% | — | `rgba(25,25,23,.8)` | 主轮廓线（卡片外框、主要图形轮廓） |
| 墨 70% | `--ink-70` | `rgba(25,25,23,.7)` | 强调正文、次级文字 |
| 墨 45% | `--ink-45` | `rgba(25,25,23,.45)` | 档案角注、图题、辅助说明 |
| 墨 25% | `--ink-25` | `rgba(25,25,23,.25)` | 细线框、分隔线 |
| 墨 12% | `--ink-12` | `rgba(25,25,23,.12)` | 构造线、背景格线 |

**硬规则**：整份 deck 不允许出现彩色。强调靠线宽、字重、字族、虚实表达，不靠颜色。

### 1.2 面板填充

- 唯一允许的填充：`rgba(255,255,255,.22)`（柔白，比纸底亮一档）。
- 禁用：纯白 `#fff`（太跳）、灰色填充（发暗发脏）、彩色色块、渐变、阴影堆叠。
- **组件质感阴影（克制）**：实心组件（卡片/面板/标本卡/图鉴块）允许带一档极淡投影提升质感，**同层级不叠影**。阴影色取**边框墨色的极淡版**（`color-mix(in srgb, var(--ink) 2%, transparent)`），比主轮廓墨 80% 淡得多，且跟随主题自动变色（`?cool` 冷白下阴影也是冷墨色）。
  - `--shadow-soft: 0 0 4px color-mix(in srgb, var(--ink) 2%, transparent)`（通用轻阴影，卡片/面板标配，零偏移极淡均匀扩散——墨色占比 2%、偏移 0、模糊 ≤6px）。
  - `--shadow-specimen: 2px 2px 0 color-mix(in srgb, var(--ink) 4%, transparent)`（标本贴纸偏移影，硬边极小偏移，仅标本卡/贴纸场景）。
- **禁令**：`--shadow-soft` 必须零偏移、墨色 ≤2%、模糊 ≤6px；`--shadow-specimen` 允许 ≤2px 硬偏移、墨色 ≤4%、零模糊。两档均禁：同层级叠影、彩色阴影、大面积铺阴影当背景——违者判不合格。

### 1.3 纸面质感（必选，缺了就不像纸）

1. **纸纹噪点**：SVG `feTurbulence`（fractalNoise, baseFrequency 0.85, 2 octaves），`mix-blend-mode: multiply`，**alpha 0.05–0.08**，铺满舞台，z-index 在内容之上、`pointer-events: none`。已内置在 `shared.css` 的 `.stage::before`。打印需保留色彩准确（`print-color-adjust: exact`）。
2. **两侧档案格线**：左右各一条 1px 竖线，距边 64px，`--ink-12`，opacity .5。已内置在 `.stage::after`。

### 1.3.1 手工质地（每页至多选一种，克制）

"不完美的有机痕迹"是高级感来源，允许但限量：

- **木刻式粗墨线**：3–6px 粗粝笔触 + 颗粒边缘（木刻/印章感），仅作全页唯一质感对比，每页 ≤1 处。
- **压印式极细放射线**：0.5px 放射/同心细线（emboss 感），适合圆形主角的冠冕。
- **颗粒 dust**：`particles.js dust`，alpha ≤.15，避开文字区，每页 ≤2 处。
- **字符即图形**：mono 字符流（`0/1/*/-/.`）以密度构成图形本体（ASCII 明暗），用 `particles.js textPoints` 采样重绘——标准手法，不限于尾卡。
- **构造线不擦除**：辅助圆、虚线基准、作图痕迹全部保留（铜版画测绘感）；精密细线可以画任何具象物（仪器/建筑/生物），不限于抽象图表。

### 1.3.2 装饰件（允许但克制，不喧宾夺主）

极细 1px 线、十字准星 `+`、角落编号系统（页码/索引）、底部一排 mono 刻度数字（贴底边、墨 45%）可作为构图件；**微型 mono 档案字**（10–12px、uppercase、字距 .3em+）贴边缘排布（右上注释块/左下段落/底部刻度排），每页 ≤2 处。

### 1.4 主题开关（URL 参数，由 `stageFit()` 识别）

| 参数 | 效果 | 使用场景 |
|---|---|---|
| （默认） | 暖纸 #DFE0D9 + 墨 #191917 | 一切页面的默认 |
| `?cool` | 冷白 #EDF0EE + 墨 #181C1E + 蓝图青 #1D5C9E 唯一强调色 | 备选冷调实验室风，整份 deck 要么不用要么全用 |
| `?mono` | 纸底不变，强制单色 | 显式声明单色时的等价写法 |
| `?ppt` | 显示左下 `.folio` 页码+署名 | 全屏放映模式；画板/编辑模式不带 |

### 1.5 高饱和强调色（`?accent` 开启，默认单色）

> 纸墨体系默认单色；只有显式开 `?accent` 才解锁彩色。**高饱和色是"整页唯一主角身上的一个点"，点睛不填充。** 番茄红为默认主强调色（焦点/数据/达标全部归它），克莱因蓝仅在需要"冷静/理性"调性的 deck 里作为备选。一页只选一档，全 deck 一致。

**三档强调色**

| 档位 | 变量 | 值 | 固定语义 | 允许载体 |
|---|---|---|---|---|
| 番茄红（默认主色） | `--accent-red` | `#C0392B` | 焦点 / 数据关键值 / 当前值 / 达标 / 否决 / 警示 | 数据大字、图表当前值、关键词、局部边框、一条主线、✕ 符号、负增长值、警示线 |
| 克莱因蓝（备选） | `--accent-blue` | `#002FA7` | 同上语义的"冷调 deck"变体；不与番茄红同页混用 | 同番茄红 |
| 墨黑 | `--ink` | `#191917` | 图形本体强调 | **只用于图形（粗线/填充/主角图形），禁用于文字** |

> 选色规则：能用红就优先用红。只有当整份 deck 的调性需要"冷/理性/科技感"时，才整份 deck 切到克莱因蓝。绝不出现"红蓝混搭"。

**硬规则**

1. **一页只有一种强调色**：每页从番茄红（默认）/ 克莱因蓝（备选）/ 墨黑三档中**只选一个**发声，全页统一，绝不在一页内同时出现两种高饱和彩。整份 deck 用红就全用红，用蓝就全用蓝。
2. **填充违禁**：高饱和色只上"线 / 字 / 边 / 小图元"，**不填充大面积底色**（色块、卡片背景、图元大面积填色都禁）。墨黑例外——墨黑填充图形本体是"图形强调"，允许。
3. **实心谨慎，空心友好**：高饱和色**优先用于空心/描边**（线框、描边字、轮廓图形、空心底），**实心填充要用得少而准**（实心核、小圆点、符号笔触可，大块实心谨慎）。
4. **hatch 可上色**：剖面斜线（hatch pattern）的斜杠**允许用强调色**描线，但只作为局部纹理点缀，不做整片。
5. **面积配额**：高饱和强调色合计**全页 ≤2.5%**，通常 0.8–1.5% 已够留下印象；超过即退化为"彩色页"判不合格。

**主角判定三问（决定"染哪个"，必走）**

每页开 `?accent` 后，先回答这三问，再动手——不满足则**宁可整页保持单色**：

- **Q1 唯一性**：这页如果只允许记住**一个**信息点，是哪个？只有那个是主角，只有它能染色。一页至多一处彩色落点（KPI 大数字页可放宽到"主角数字本身"一处，不含其单位/标签/边框）。
- **Q2 最后手段**：去掉颜色，靠字重/线宽/字族/虚实还能不能表达同等强调？能则**不许染色**——颜色是字重线宽都失效后的最后手段，不是首选。
- **Q3 配额**：染色面积 ≤ 全页 2.5%？超过即不合格，砍。

**禁染清单（以下元素永不染色，无论是否主角）**

- 栏题 / 栏号 / 图例 / 刻度 / 轴标注 / 页脚 / FIG 编号 / doc 角注 → 永不彩色
- 装饰性重复元素（多个同形态节点、多根等高柱、多张等格卡）→ 只选**其中之一**染，禁止批量染
- 纯标注字"FOCUS / CURRENT / HIGHLIGHT / 关键" → 不加。颜色本身已是标注，再叠文字标签是画蛇添足
- 单位、副标签、EN 译名 → 跟随墨色阶梯，不跟随主角染色

**数据类高亮细则**

- 图表/数据页的**当前值、关键值、达标值**若是本页主角 → **主角格整体染色**（数值+单位+标签+EN+局部边框可全染），让焦点格作为一个完整单元被识别；非主角格保持墨色阶梯。
- **负增长、下降、错误、未达标**天然契合番茄红的"否决/警示"语义，是番茄红最典型的用场。
- 数据轴标注（刻度、网格线、标签）**永不彩色**，让彩色只落在数据本身。
- hatch 剖面斜线：主角格内的 hatch 斜杠**可跟随主角染色**（描线变强调色），强化焦点。

**落地纪律**

- **样板先行**：强调色改动必须先做 ≤4 个样板经确认，再按同一标准分批铺开；**严禁一次性改全量**。
- **双模式验证**：每个改动版式必须验证两遍——无 `?accent` 时渲染与单色版完全一致；有 `?accent` 时**只有预定的主角格/主角元素**变色。不符合即回退。

**判定口诀**：`一页一色，主角格整体染色，线字边 hatch 都可行；栏题图例刻度永不染；番茄红=默认主色（数据焦点+否决警示），克莱因蓝=冷调备选，墨黑=图形强调。`

## 二、字体与字重

### 2.0 Font Mixing（衬线 × 无衬线混排原则）

- **Titles / Quotes / Big Statement → 衬线气质族**：体现社论权威感与"出版物气质"。本体系内由两族承担：**思源宋体 Medium**（statement 大字、落版标题、提问符号）、**霞鹜文楷大字**（引用/金句，衬线笔触）。
- **Body / Data / UI / Labels → 无衬线族**：确保屏幕易读与信息密度可控。本体系内由两族承担：**思源黑体**（正文/说明/标签）、**Courier Prime**（数据/编号/字段码）。
- 同页混排是常态：大字衬线气质 + 正文无衬线，靠字族拉开层级，不靠颜色。

### 2.1 四族字体（全部开源可商用，本地 `@font-face` 加载，分工不重叠）

| 族 | 字体文件 | CSS 变量 | 字重 | 职责 | 禁令 |
|---|---|---|---|---|---|
| 大字族 | 思源宋体 Medium SourceHanSerifCN | `--serif` | 500 | 大字标题、金句、结论、大数字、提问符号 | 全 deck ≤3 页用大字；不用于正文 |
| 正文族 | 思源黑体 Light | `--sans` | 300 | 正文、说明、卡题、栏题、标签、caption、小字 | 不引入 Regular；需要强调时升字族（转宋体）或加线宽，不升字重 |
| 档案族 | Courier Prime | `--mono` | 400 | 编号、图题、字段码、刻度、坐标、页脚 | 不承担长句叙述 |
| 手写族 | 霞鹜文楷 LXGWWenKai | `--brush` | 400 | 手写批注、圈错 | 全 deck ≤3 处，只圈错处 |

字重纪律：**越大越轻，越小越实**。大字只用思源宋体 Medium 500（衬线字形本身已具出版物分量，Medium 比 Bold 更文气、与纸墨克制气质契合）；思源黑体**只有 Light 300 一档**——全字号统一 300，从小字到大标题都不升字重，需要强调时转宋体字族或靠线宽/颜色，而不是加粗。

### 2.2 字号阶梯（1920×1080 舞台坐标系）

| 层级 | 字号 | 字体/字重 | 用途 |
|---|---|---|---|
| giant | 76px（上限 96） | 思源宋体 Medium | 金句、落版大字 |
| h1 | 60px | 思源宋体 Medium | 页面主标题（statement 页） |
| h2 | 40px | 思源宋体 Medium | 次级大字、提问符号 |
| caption | 32–36px（基准 33–34） | 思源黑体 **300** | 底部一句结论 |
| 卡题/栏题 | 24–26px | 思源黑体 300 | 卡片标题、栏目标题 |
| 正文/说明 | 18–22px | 思源黑体 300 | 条目、字段说明、气泡文字 |
| 字段码/数据 | 13–20px | Courier Prime | INPUT/LATENCY 等字段码、数字 |
| 图题 FIG. | 15px | Courier Prime + 字距 .3em | 图版编号 |
| 角注/页脚 | 13px | Courier Prime + 字距 .22em | doc 角注、folio、时间码 |

### 2.3 档案族排版细节

- 英文一律 `text-transform: uppercase` + `letter-spacing: .22–.3em`。
- 字距用 `text-indent` 补偿保持视觉居中（居中 mono 文字加等宽 text-indent）。
- 中文原则上不进 mono（Courier Prime 无中文字形，走 per-glyph fallback）：**mono EN + 中文短注混排可接受**（如 `w ≈ 0.91 · 它看见的`），但中文长句、大字号中文禁用 mono（fallback 破坏灰度）。

## 三、线宽与图形语言

### 3.1 线宽规约（全套统一，以样本 S09 档位为基准）

线宽分两大类：**UI 组件边框一律 1px**（靠颜色浓度分层，不靠粗细）；**SVG 图形轮廓保留多档线宽**（线宽即语义，承载权重/主次）。

| 线型 | 宽度 | 颜色 | 用途 |
|---|---|---|---|
| **UI 边框** | **1px** | 墨 38–80% | 卡片外框、面板、气泡、按钮、chip、表格行、筛选框、outline——一律 1px，深浅靠颜色阶梯 |
| 主轮廓（SVG） | 1.2–1.4px | 墨 80% | 主要图形轮廓（非 UI 组件）、主角图元外框 |
| 内框线 | 0.6px | 墨 35% | 双线卡框的内圈（内缩 4–5px） |
| 分隔线 | 0.8–1px | 墨 50% | 卡内分隔、栏间分隔 |
| 构造线 | 0.5–0.7px | 墨 25–45%，虚线 `3 5` 或 `2 6` | 十字基准、象限轴、引线 |
| 强调线 | 1.8–2.2px | 墨 100% | 权重最高的一条（弧/流/主线），每页至多一处；**符号笔触（✓/✗/手写符号，3–3.5px 短 path）不计入此限** |
| 剖面填充 | 0.7px 45° 斜线，间距 5–9px | 墨 35% | hatch pattern，表实体/投影/选中 |

### 3.2 双线卡框（全套通用卡片件）

外框 **1px** @ 墨 80%（UI 边框）+ 内框 0.6px @ 墨 35%、四边内缩 4–5px。卡片内部标配：编号/短横 → mono EN 角标 → 中文卡题（300/24px）→ 分隔线 → 圆点字段行（中文 300/19–21px + 右侧 mono 13px 字段码）。

### 3.3 节点与连接件

- 落点：双圈 + 实心核（外圈 1.2px + 内圈 0.6px + r2.4 实心点）。
- 箭头：细线开放箭头（两条 1.2–1.4px 线段成角），禁用实心三角箭头。
- 引线：0.7px 虚线 + 中点 2.4px 小圆点。
- 刻度：主齿 1px、副齿 0.5px，配合 mono 数字——时间轴、圆环、尺子共用。
- 尺寸标注：端点短刻度 + 虚线引上线 + mono 数字（如 `50 m`、`280 PX`）。

### 3.4 手绘批注族（每处都是"人"的痕迹，限量使用）

- 旋转 ±3–5° 的椭圆圈（两笔叠出：第二笔 opacity .45–.55、反向旋转）。
- 霞鹜文楷手写文字，可整体旋转 -1.5–-3°。
- 断口表达"缺失/错误"：纸色 rect 擦除 + ✕ 两笔细线，或虚线 + 撕裂毛边。

### 3.5 粒子语言（particles.js，= 画面的质地而非装饰）

| 函数 | 语义 | 用法 |
|---|---|---|
| `cluster` | 高斯点簇：token/节点的物质感 | 主角形态 |
| `dust` | 氛围尘埃，alpha ≤ .15 | 避开文字区，每页至多 2 处 |
| `arc` / `brokenArc` | 点流弧 / 断弧散落 | 连接与断裂的叙事 |
| `textPoints` | 文字轮廓采样 → 粒子重绘 | 尾卡大字、粒子海报 |

规则：粒子是"密度与秩序"的语言——秩序网格=正确/结构，缺粒坠落=错误/异常。**不是每页都要用**，叙事图版页（卡片/流水线/时间轴）不用粒子。

### 3.6 自由 SVG 绘制规约（语义图形语言）

上位原则只有一条：**图形必须携带语义，装饰性重复不是图形。** 画任何元素前先问"它的形状说出了什么"。

**① 线型即语义（固定映射，全 deck 一致）**

| 线型/手法 | 语义 |
|---|---|
| 实线 → 虚线 → 疏虚线（渐虚） | 粒度拉远 / 确定性递减 / 不可见过程 |
| 线宽三档（0.6 / 1.1 / 1.4+） | 权重、主次、流量大小 |
| 虚线容器（圆角/直角逐区） | 系统边界、责任域、旁路（不并入主流程） |
| 断口 + ✕（纸色擦除） | 否决、缺失、错误、不并入 |
| hatch 剖面 | 实体、拦截物、选中、投影 |
| 双圈+实心核 | 落点、站位、标本钉 |
| 回环弧箭头 | 闭环、迭代、反馈（弧上必须挂语义标签） |
| 肘形引线（先横后斜，单调不交叉） | 图中元素 → 边缘标签栏的归属 |

**② 共享坐标系**：多行/多段内容共用一条刻度尺 + 虚线栅格（尺子在上或下，mono 数字），元素以"标本钉"落刻度——禁止每行各自为政的平行元素。

**③ 仪器化图元**：流程/步骤页的每段图元必须形态各异（单据纸/甘特条带/刻度表盘/报告卡/芯片组），像一排不同的仪器；图元 200–600px，不做框内小图标。

**④ 构造线不擦除**：辅助圆、虚线基准、作图痕迹保留（铜版画测绘感）；十字准星 `+` 做套准标记。

**⑤ 复合骨架三件套**（战略框架页用）：顶部阶段链 → 中部维度矩阵（左竖排维度栏 × 右列区）→ 底部 chevron 收束条；层间用细线分隔，信息密度最高页型，数据仍全部自编。

**⑥ 反馈回路**：主链之外的双向/返回关系用虚线弧 + 弧上标签（mono 小字），不从主链节点直接横穿画面。

**⑦ 禁区**：同构矩形阵列（同款框 ≥3 充当主体）、框内小图标充当图元、实心三角箭头、为填满而加装饰。

## 四、留白与画面组织

### 4.1 舞台与骨架

- 固定舞台 **1920×1080**，`.stage` 相对定位、`overflow: hidden`；`stageFit()` 按 `min(vw/1920, vh/1080)` 等比缩放居中。
- **一页一个 HTML 文件**（`frames/shot-NN.html`），页与页之间不共享运行时状态。

### 4.2 固定件三件套（每页必备）

1. **左上档案角注 `.doc.tl`**：top 44 / left 48，mono 13px、字距 .22em、行高 2.1、墨 45%，两行：`项目 — 章节` / `本页关键词`（英文大写）。
2. **底部居中结论 `.caption`**：`left/right: 0`、`bottom: 100–126`（基准 118）、text-align center、思源黑体 **300**、33–34px、字距 .04em、z-index 5。一句陈述句，句号收尾。尾卡页可无 caption。
3. **左下页脚 `.folio`**：left 48 / bottom 44，mono 13px、字距 .22em、墨 45%，格式 `NN / TOTAL — BY 署名`。**仅 `?ppt` 模式显示**（`:root.ppt .folio { display:block }`）。

### 4.3 图题组件（工程制图页标配）

`FIG. NN — 标题`：mono 15px、字距 .3em、墨 45%，位置 x180–220 / y176–192，下方配 0.6px @ 墨 30% 短横线（长约 260–340）。叙事插画页、UI 写实页可省略。

### 4.4 安全区与留白纪律

- 左右边距：常规 150–220px；满幅 UI 页可收到 100px。
- 内容纵向区间 **y170–880**；caption 上方（y900+）必须留空，不压 caption。
- **可用空间双向居中（硬规则）**：每页内容主体必须在"可用空间"内**水平 + 垂直双向居中**。
  - **可用空间定义**：剔除固定件后的矩形——左右为边距之间（常规 x150–1770），上下为 y170–880（剔除左上 `.doc.tl` 角注区与底部 `.caption`/`.folio` 区）。
  - **水平居中**：内容主体的几何中心（非视觉重心）落在可用宽度中点（常规 x960）±10px。多区块构图（如上矩阵 + 下 KPI 带）各区块中心也必须对齐到同一中点。
  - **垂直居中**：内容主体在 y170–880 内上下留白大致均等；禁止内容整体偏上（下半页全空）或偏下（压 caption）。
  - **判定方法**：用浏览器量内容包围盒（`getBBox()`），左右边界的中点必须 ≈ 可用宽度中点；上下边界的中点必须 ≈ (170+880)/2 = 525。偏移 >10px 即不合格，必须整体平移修正。
- **一页一个主角**：主角图形占画面 40–70%，在可用空间内居中展开；其余全部退让为标注与留白。封面/Outro/金句页留白必须 **>60%**。
- **构图平衡**：多元素构图的视觉重心必须落在中轴 x960 ±10% 内，或左右明确配平（左图右文 / 左文右图）；内容主体带为 y260–840，禁止内容带悬浮在上半页、下半页全空。
- **视觉平衡 65/35**：内容（文字信息）≈65% + 视觉元素（图形/装饰）≈35%；图形化表达优先于表达组件，但图形不淹没信息。
- 信息密度上限：文字块不超过 3 个层级；每页强调线 ≤1 处、大字 ≤1 处、手写批注 ≤1 处。
- 禁止：标题+正文+结论条的传统幻灯片三段式骨架；多主角并列抢视线；**同构矩形阵列**（>3 个同尺寸同结构框排成行/列，无层级无主角）；把留白当"没排满"去填。

### 4.5 节奏策略（整 deck 观感）

- **纯色纪律**：整份 deck 全部纸底 `#DFE0D9`。**禁止整页深色底**（含 `#191917` 及任何低亮度底色）——墨只用于线条与文字，不当底色。
- **节奏靠纸底页型穿插**：每 3–4 张信息硬页插 1 张呼吸页——章节隔页（超大编号+章节名，留白 >60%）、金句页（纸底超大衬线）、粒子海报页或极简图版页。
- **强调手段白名单**（不靠反色）：字级对比、线宽档位、留白比例、双线卡框、主角占比。
- **Flow**：保持 `硬 - 硬 - 呼吸 - 硬` 或 `硬 - 呼吸 - 硬` 穿插，避免连续 4 张以上"信息硬页"。

### 4.6 页面类型四轴（选版式时先归类）

| 类型 | 特征 | 代表页 |
|---|---|---|
| 叙事插画页 | 场景画/标本卡，有故事角色，可配手写批注 | 聊天标本、洗车场景 |
| 工程制图页 | FIG 图题 + 精密细线图版（流水线/时间轴/矩阵/树/漏斗） | 大多数概念页 |
| 粒子海报页 | 粒子密度主角 + 极少文字，情绪页 | 黑匣子、金句、尾卡 |
| UI 写实页 | 产品界面线框 mock，信息密度最高，数据全部自编 | 后台 Trace 列表 |

### 4.7 间距网格（4pt baseline，排版硬规则）

所有盒模型间距（padding / margin / gap）必须是 **4pt 基线网格**的整数倍，禁止随手写绝对值。这是整套版式"整齐感"的来源——所有间距都落在同一把尺子上，视觉节奏才统一。

**间距档位表**

| token | px | 典型用途 |
|---|---|---|
| `--space-1` | 4 | 内描边补偿、最小呼吸 |
| `--space-2` | 8 | 紧凑字段内距、图标与字间距 |
| `--space-3` | 12 | 字段行内 gap、小卡内边距 |
| `--space-4` | 16 | 卡片标准内边距、条目 gap |
| `--space-5` | 20 | 卡片宽松内边距 |
| `--space-6` | 24 | 区块间 gap、标本卡内距 |
| `--space-8` | 32 | 大区块内距、面板呼吸 |
| `--space-10` | 40 | 面板宽内距 |
| `--space-12` | 48 | 双区面板内距 |
| `--space-14` | 56 | 栏间宽缝 |
| `--space-16` | 64 | 两侧档案格线距边 |
| `--space-20` | 80 | 主区横向间距 |
| `--space-24` | 96 | 封面/Outro 大留白单元 |
| `--space-30` | 120 | 条目纵向间距（B41 基准） |
| `--space-40` | 160 | 安全区常规边距上限 |

**硬规则**

- padding / margin / gap 的每个 px 值都必须落在上表，**禁止 15 / 6.5 / 26 / 14 / 10 / 7 / 22 这类"凑近"值**。
- 写 CSS 时优先引用 `var(--space-N)`；若用裸 px 也必须等于表内值。
- **例外（不归网格管）**：工程制图刻度齿（如 38px 主齿）、节点半径（r9/r16）、形态尺寸（卡片宽高如 470×300）属"测绘感设计语言"，保持各版式给定值；安全区坐标（左右 150–220、纵向 y170–880）是坐标参照而非盒模型间距，维持现状。

### 4.8 对齐纪律（三律，排版硬规则）

> 对齐是版式"整齐感"的另一个来源，与 §4.7 间距网格正交：**网格管"间距是多少"，对齐管"谁和谁共线"**。本节解决"多个元素该不该对齐、对齐到哪、位移怎么取"——禁止 case-by-case 凭感觉挪。

**律一 · 结构线锚定**

同一页面里**结构同类**的元素必须共享一条公共结构线，不得各自为政。"结构同类"按以下三类判定：

| 结构同类关系 | 必须共线的结构线 | 典型场景 |
|---|---|---|
| 同属一个信息柱（落版列：kicker / title / subtitle / meta） | **左边缘**共线 | 封面 meta 块锚定到标题列首元素左边缘 |
| 同属一组图表（chart wall / 多图联排） | **纵轴 / 底部基线 / 标题首字母→绘图区缩进** 三者各自共线 | 折线图与柱图纵轴共线；不同图表底部标签共线；各图表标题到绘图左边缘的缩进一致 |
| 同属一个对象的附属标注（SOURCE / 来源注 / 引线标签） | **锚定到所属对象**，不贴页面固定件 | 图表来源注垂直居中于该图表，而非贴 caption 行 |

> 判定法：每加一个元素先问"它结构上和谁同类"——同类则查上表对齐，无同类（真正孤立的装饰）才允许自由定位。

**律二 · 视觉配平优先于坐标好看**

当律一的共线无法满足、或元素是真正孤立的主图元时，其水平位置服从**整体视觉重心落在中轴 x960 ±10%**，而非孤立的"看起来还行"坐标。

- 例：封面右半区的线稿小图，经律一检查无结构同类项（左侧是文字柱、它是独立图形），则按视觉配平定位——若左半文字重、右半空，小图应向左收（缩小与主体的间距），让全页重心回中。
- **律一 > 律二**：律一要求共线时，不得为"视觉配平"破坏共线；先共线，再在共线约束内做配平微调。

**律三 · 位移落网格（与 §4.7 的衔接）**

任何**整体平移**操作的位移量，按目的分两种取值法，禁止混用：

| 平移目的 | 位移量取值 | 例子 |
|---|---|---|
| "挪到更好看 / 更平衡"（无对齐目标） | **必须落 4pt 网格**（§4.7 档位表：12/16/24/32…） | D5 章节隔页整组垂直居中 → 上移量取 40 或 44，不取 43 |
| "对齐到某已存在元素的几何精确位置" | **位移 = 两位置坐标差，可脱离网格** | chart02 底部标签对齐 chart03「退货」→ 位移由退货坐标算出，不取整 |

> 判定法：先问"这次平移有没有对齐目标"。有 → 位移是算出来的（可非网格）；没有 → 位移必落网格。"对齐目标"包含：对齐到某元素边缘/基线、对齐到可用空间中轴或页面中心（§4.4 双向居中的位移归此类）。这条堵住"下移 13px / 上移 43px"这类伪装成对齐、实为凑好看的违规。

**与 §4.4 / §4.7 的关系**

- §4.4 双向居中管"内容主体整体在可用空间内的位置"；本节管"主体内部多个元素之间"的对齐。整页居中先用 §4.4，内部对齐再用本节。
- §4.7 网格管间距数值；本节律三规定"位移何时归网格、何时可脱离"。两节配合：间距永远归网格，位移视目的而定。

**口诀**：`同类共线（柱左齐 / 图轴齐 / 标注锚对象）；孤立配平（重心回中轴）；位移看目的（有目标算差值，无目标落网格）。`
