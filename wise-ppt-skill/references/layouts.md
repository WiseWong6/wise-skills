# 纸墨线稿 · 版式目录（Layouts）

> 从《Trace》20 页成品分镜 + eval/ppt 重排 + 外部版式参考（磐石/Becomewiser/微保/太和/QQ秀/频道/P10/融资/风控/手册/工商协同，结构借鉴、配色不借、数据不搬）提炼的 59 种页面组织形式。
> 每种版式给出：用途 / 结构 / 关键坐标（1920×1080 舞台）/ 文字层级 / 样本页。
> 选版式先于写代码：先用文末「选用速查」把内容归类到 MECE 内容族，再定版式动笔。坐标是参考基准，可按内容微调，但三件套（doc 角注 / caption / folio）位置不动。
> **图形化优先**：版式只给骨架，主体图形优先自由绘制程序化 SVG（规约见 design-tokens 3.6）；禁止把"同构框+字+箭头"阵列当图形。

## A. 叙事插画页

### A1 · 标本卡（截图/对话/文档标本）
- **用途**：展示"证据原件"——一段对话、一张单据、一个界面片段，配批注圈错。
- **结构**：中央偏上 DOM 面板（柔白填充 `rgba(255,255,255,.22)` + 1px 墨 32% 边框 + 圆角 16–18 + 轻偏移影），面板顶部 mono 编号牌；下方 SVG 手绘椭圆圈（旋转 ±4°，两笔叠出）圈住错处，细线引到居中手写批注（文楷，可整体 -1.5°）。
- **坐标**：面板 w≈920 居中或偏左 x300；批注区 y≈700 居中；caption bottom 108。
- **文字**：面板内正文 300/22px、行高 1.8；批注文楷 40–84px。
- **样本**：shot-01（估分梗聊天标本）。

### A2 · 场景画（横向叙事插画）
- **用途**：把抽象问题演成一个具体场景（人、物、地点的左→右叙事）。
- **结构**：整版程序化 SVG：地平线（y≈740）+ 自左向右的场景角色（贝塞尔轮廓 + 45° hatch 剖面影），上方 1–2 个 DOM 对话气泡（圆角 16，墨 38% 边框），底部尺寸标注线（端刻度 + 虚线引上线 + mono 数字）+ 可选文楷吐槽。
- **坐标**：地平线 x150–1770；气泡 y≈170 左右各一；caption bottom 108。
- **文字**：气泡 300/26px；场景标签 mono 14–16px；招牌类中文 400/34px。
- **样本**：shot-02（洗车店 50 米）。

### A3 · 文献摘引页（摘要 + 原文标本）
- **用途**：引用政策文件、权威报告为论点开路——兼顾"可信原文"与"读者速读"。
- **结构**：上半部转述摘要（整段 300/20px，关键句用双线 underline 或墨点强调，不用彩色高亮）；下半部嵌入原文标本框（双线框内模拟红头文件/网页版式：报头横线 + 标题行 + 正文灰行暗示），可 1–2 张并排。
- **坐标**：摘要区 x150–1770、y180–460；标本框 x300–1620、y500–940（双框则各 640 宽并排）。
- **铁律**：标本框是"文献线稿"（版式暗示），禁贴真实文件截图；文件名、机构名全部自编。
- **样本**：参考《产品手册》《工商协同》政策摘引页结构。

## B. 工程制图页

### B1 · 横向流水线（3–4 段）
- **用途**：解释过程机制（输入 → 黑盒 → 输出 / 步骤链）。
- **结构**：一条**共享基线尺**（主齿+副齿+mono 刻度）贯穿全段，段间等长细线开放箭头坐在尺上；每段一个**仪器化图元**吊在尺上方（虚线吊点），步骤编号圆环嵌在尺下对应站位，EN+中文说明跟在编号下。
- **铁律**：**每段图元必须形态各异**（单据纸/甘特条带/刻度表盘/报告卡/芯片组…像一排不同的仪器），禁止同款双线框重复 ≥3 段充当图元；不设脱离基线的独立漂浮步骤行。
- **坐标**：基线 y≈520–590；图元带 y300–520；编号与说明 y600–750；段均布 x280–1640。
- **技巧**：等宽间隙/等长箭头的制图对齐；最重的一段（表盘/黑盒）放大成全页视觉重心。
- **样本**：shot-03（next-token 预测）；eval/ppt shot-04（评测链·仪器化四段）。

### B2 · 权重弧线图（arc diagram）
- **用途**：表达节点间连接强度 / 注意力 / 引用关系。
- **结构**：一排 token chips（双线框，y≈530）+ 下方索引刻度 t0–tn 与虚线基线；上方多层贝塞尔弧，**线宽/透明度三档编码权重**（弱 0.6px@.2 / 中 1.1px@.4 / 强 1.8px@.9），弧顶 mono 标权重；断裂弧 = 虚线 + 纸色 rect 擦除断口 + ✕ + 引线标注。
- **坐标**：token 行 y532 均布；构造基线 y636。
- **样本**：shot-04（注意力断线）。

### B3 · 虚实步骤串（不可见过程）
- **用途**："中间发生了什么你看不见"——两端已知、中间未知的过渡页。
- **结构**：左/右两个实线圆角气泡（已知端点），中间 3–4 个**虚线**圆角框（未知步骤）虚线箭头相连；顶部 mono 小注 + 短细线。
- **技巧**：虚线即"不可见"的视觉隐喻，实虚对比就是全部叙事，不加多余解释。
- **样本**：shot-05（不可见的过程）。

### B4 · 对比双面板（大字 VS）
- **用途**：两种模式/两个世界的强对比（旧 vs 新、传统 vs AI）。
- **结构**：左右双面板（520×560，双线框 + 顶部页签）+ 中央双圈 VS 徽章；每面板内：中文四字短语（400/34px）+ 实墨 ✓/✗ 符号（3.5px 笔触，与文字间留 30px+ 间距）+ 下方小图形演绎 + 一行注解。
- **坐标**：面板中心 x560 / x1360，y270–830；VS 圆 (960,460) r34+40。
- **样本**：shot-06（错误中断 vs 错了继续）。

### B5 · 分水岭双栏（克制对比）
- **用途**：同类两概念的字段级对照（比 B4 更冷静、更信息向）。
- **结构**：中轴竖线 x960（带 38px 刻度齿、中段留 VS 缺口）；左右栏各 680 宽：栏头（中文标题 + 右对齐 mono tag + 双线分隔 + 虚线引线到中轴）+ 4–5 行字段（圆点刻度 + 中文小标题 + mono 字段码，虚线竖分隔出说明列）。
- **技巧**：无卡片无外框，纯"表格制图"；行间 0.6px 分隔线。
- **样本**：shot-12（Context vs Memory）。

### B6 · 水平时间轴
- **用途**：历史沿革、版本演进、里程碑。
- **结构**：主轴横线（y≈560，x200–1720）+ 38px 次级刻度齿；节点双圈点（普通 r9 / 高亮 r16+r20），上方年份(mono 28px，高亮 34)/名称/机构三段短引线连轴，下方注释；单点高亮叙事（手绘弧线标记）。
- **样本**：shot-08（Trace 简史）。

### B7 · 四象限矩阵 + 中心圆标
- **用途**：定义页——一个核心概念由 N 个组成部分构成。
- **结构**：中心双圈圆标（r≈92，mono 概念名 + 中文副题）+ 四象限双线卡（330×150：mono EN 题 + 短横 + 中文 400/26 + 说明 300/18）；象限到中心的虚线构造连线（中点落小圆点）+ 十字虚线基准轴（0.5px `2 6`，opacity .25）。
- **坐标**：圆心 (960,590)；象限 x420/x1180、y330/y690。
- **样本**：shot-09（什么是 Trace）。

### B8 · 环节树 + 规格单（过程+产物双区）
- **用途**：左讲结构（一棵树/一条链），右讲字段（每节点记什么）。
- **结构**：左区：根节点 hatch 填充框 + 竖干连接线（0.8px，带落点圆点）下挂子环节框（双线框 560×48，中文 300/21 + 右侧 mono 注记 + 耗时刻度），尾部虚线输出框；右区：双线大框（620×620）内字段规格单（mono 字段码 + 中文说明，行间 0.6px 线，异常行虚线框单独强调）。
- **坐标**：左区 x180–900；右区 x1130 起。
- **样本**：shot-11（Trace 拆解）；同族变体 shot-15 右侧规格卡。

### B9 · 汇聚流（merge 图）
- **用途**：多源输入合并为一个产物（Prompt 组装、数据汇总）。
- **结构**：左 1–2 张源卡（470×300）→ 贝塞尔细流（1.2px）弯入合并点（双圈+实心核+竖向构造虚线+mono MERGE 标）→ 合并后 2.6px 粗线箭头入右侧结果大卡（500×450）→ 输出箭头。
- **技巧**：**细流→粗干线宽分级表权重**；卡底刻度脚装饰。
- **样本**：shot-13（Prompt 节点）。

### B10 · 三向放射（爆炸图）
- **用途**：一个节点的输入/输出/参数三向展开。
- **结构**：中心双线框节点 + 左竖轴挂输入字段（右对齐）、右竖轴挂输出字段（左对齐）、下横轴均布参数；分支线端落小圆点，字段统一 mono 17px 上行 + 中文 300/16px 下行双行格式。
- **坐标**：中心 (960,520)；左轴 x560、右轴 x1360、下轴 y700。
- **样本**：shot-14（LLM 调用节点）。

### B11 · 漏斗（连续收敛）
- **用途**：数量级递减的过程（检索召回→重排→输出、筛选漏斗）。
- **结构**：连续倒三角，顶宽 700–820、**两侧边一路收为塔尖**（`wAt(y)` 连续宽度函数，不要平底梯形）；横向分隔线切层，每层中央层名 + 左侧虚线引出 mono 数量 + 右侧实线引出字段注记；顶部刻度尺；塔尖墨点滴入下方双线小框（出口）。
- **坐标**：中轴 x660，顶 y250、尖 y810；右侧可配规格单卡（x1380）。
- **样本**：shot-15（检索漏斗）。

### B12 · 循环圆环
- **用途**：闭环流程（定位→调优→评测→治理、持续回归）。
- **结构**：圆心主环（R240，1.4px + 内虚线环 + 15° 刻度齿避让节点角度）+ 4 段顺时针弧箭头；四角外侧双线卡（620×152）虚线引线挂到环上 45° 双圈节点；圆心十字 + mono 主题字。
- **坐标**：圆心 (960,515)；卡 x60/x1240、y268/y610。
- **样本**：shot-10（Trace 作用闭环）。

### B13 · 同心防线（径向层级）
- **用途**：防御层级 / 包裹关系（guardrail、校验圈层）。
- **结构**：同心三环（R80/190/300，各配内细环 + 15°/30° 刻度）+ 十字虚线构造线；内核放主体，环标签置环带上；环外条目用径向引线（环上落点→短引线→外置小字，左半 text-anchor:end / 右半 start 自动换锚）；可配左下独立小卡（hatch 角块 + 勾号列表）贝塞尔虚线连内核。
- **坐标**：圆心 (1050,530)。
- **样本**：shot-17（Code & Guardrail）。

### B14 · 甘特瀑布（时间定位）
- **用途**：耗时分布、瓶颈定位、断点标注。
- **结构**：顶部时间刻度尺（主齿 + mono 数字 + 竖向虚线栅格贯穿全图）+ 横向 span 条带（hatch 填充 + 起止端强调竖线 + 上方时长标签）；断口表达：虚影缺失框 + 撕裂毛边 + 崩解粒子簇 + 手绘双椭圆圈 + 引线归因标注。
- **样本**：shot-11-waterfall-bak（备用稿，需时启用）。

### B15 · 星座映射网（组合/映射关系）
- **用途**：多对多映射、证据组合、引用网络——"哪些原子组成哪些产物"一图看清。
- **结构**：左侧原子节点竖排（小方块或双圈点 + mono 名 + 中文注，y 均布）；右侧产物名（中文 400/22px + mono EN 注）；贝塞尔细弧从原子汇聚到产物，**线宽/透明度三档编码权重**（弱 0.6px@.2 / 中 1.1px@.4 / 强 1.8px@.9）；共享竖向虚线构造基线 + 顶部 mono 刻度。
- **技巧**：节点即标本钉，弧即语义；禁止退化成"左 chip → 线 → 右文字"的同构行阵列。
- **样本**：eval/ppt shot-09（证据组合→指标）。

### B16 · 嵌套变焦框（粒度递进 / 观察层级）
- **用途**：同一对象的观察粒度逐层拉远（单轮 ⊂ 会话 ⊂ 过程 ⊂ 结果）、放大/缩小层级关系。
- **结构**：同心嵌套方框（或圆框）3–4 层——最内层实线 + hatch 核（最细粒度），向外线型渐虚（实线 → 虚线 → 疏虚线）；十字构造基准线超出最外框、四角套准 `+` 标记（构造线不擦除）；中心双圈观察点。
- **标签**：右侧标签栏按"外→内 = 上→下"排序，每层框右上角出**肘形虚线引线**（先横后斜，单调不交叉）到标签块（mono 序号+EN / 中文层名 400 / 小注 300）。
- **坐标**：图心 (660, 520)；内层半宽 80，每层 +65–80；标签栏 x1080 起，四档 y280/430/580/730。
- **铁律**：禁止退化成递升阶梯上的同款框阵列——"嵌套"本身就是粒度语义。
- **样本**：eval/ppt shot-06（四层观察单位）。

### B17 · 蛇形回环（6–8 步流程 + 迭代语义）
- **用途**：步骤多于 4 的长流程，且含"上线/迭代/回归"回环语义（B1 装不下、B12 圆环又太抽象时用）。
- **结构**：上排 3–4 节点左→右（双线框或仪器化图元，下方挂圆点字段行），右端大弧弯下（1.4px），下排节点右→左返回，左端回环弧挂**迭代标签**（mono 竖排或弧侧小字，如"持续迭代"）；弧=语义，节点=步骤。
- **坐标**：上排 y≈360、下排 y≈640；节点均布 x260–1660；回环弧半径 90–130。
- **铁律**：节点必须带字段行或微图形，禁止纯文字 chip 排队；回环弧必须有标签，无标签的回环是装饰。
- **样本**：参考《磐石 1.0》上线旅程页结构（蛇形+冲刺/迭代双标签）。

### B18 · 链阵复合（阶段链 × 维度矩阵，战略框架页）
- **用途**："N 个阶段 × M 个维度"的战略/业务框架（阶段链下挂指标/触点/动作矩阵）。
- **结构**：**三段复合**——顶部：阶段链（3–5 站，圆环序号+短横+阶段名，细线箭头）；中部：矩阵（最左竖排 mono 维度栏 2–4 行 × 各阶段列，列内小字段 2×2 排布，行间 0.6px 分隔线）；底部：chevron 收束条（每阶段一个箭头块，mono 一行结论）。
- **坐标**：链 y≈280；矩阵带 y380–800；chevron y≈840（避开 caption 则收至 820）；维度栏 x150–260，列区均布 x300–1720。
- **铁律**：这是信息密度最高的页型（适用"数据自编"纪律）；全页只允许细线分隔，禁止彩色色块与厚底卡片；一份 deck 至多 1–2 页。
- **样本**：参考 Becomewiser 架构图「业务模型/运营链路」结构（链-阵-底注三段）。

### B19 · 分层架构堆栈（平台/能力分层）
- **用途**：技术/业务架构总览——"平台分几层、每层有什么"（最高频商业版式）。
- **结构**：左侧竖排 mono 层标签列（L1/L2/L3…+中文层名）× 右侧每层一条横带，带内均布能力件（细线小框或仪器化图元，3–6 个）；层间 0.6px 分隔线贯通；顶层/底层可放宽为通栏带（标题层/基础层）。
- **坐标**：标签列 x150–300；横带区 x330–1780；每层高 110–150，y240 起。
- **铁律**：能力件不是同构框阵列——每层带内图元形态随语义微调（引擎=齿轮圆、模型=方块、数据=圆柱），层数 3–5 层为宜；层标签与横带严格左对齐。
- **样本**：参考《磐石 1.0》分层架构页、《微保》平台层结构（结构借鉴、数据自编）。

### B20 · 底座托举三层（自下而上支撑）
- **用途**："底层平台支撑中层能力、中层支撑上层产品"的价值传递。
- **结构**：底部一条通栏底座带（hatch 或双线框，mono 平台名）→ 向上 1–2 根开放箭头 → 中层能力卡带（3–4 卡）→ 向上箭头 → 顶层产品/场景卡带；箭头即"托举"语义，层级自下而上读。
- **坐标**：底座 y780–860 通栏；中层带 y520–700；顶层带 y260–430；箭头居中或双箭头 x760/x1160。
- **铁律**：三层为限；箭头必须细线开放箭头；卡带内图元按 B19 铁律做形态区分。
- **样本**：参考《磐石 1.0》平台-能力-产品页结构。

### B21 · 痛点→解法→成效三栏（含证据-诊断-建议变体）
- **用途**：销售/汇报叙事的最小闭环：问题是什么 → 我们怎么做 → 结果多大。

- **样本**：参考《产品手册》发展史页、《工商协同》沿革页结构。

### B43 · KPI 大数字横带（一锤定音）

- **铁律**：数字 ≤4 个；数字即主角，禁加第二图形；单位与数字不同字级（数字 96+ / 单位 24）。
- **样本**：参考《产品手册》实力数字页、案例成效页结构。

### B44 · Logo 云墙（伙伴背书，低频）
- **用途**：客户/伙伴/资质背书，以数量制造信任感。
- **结构**：顶部一行统计性导语（中文 400/26px + mono 数字）；下方 6–8 列 × 4–5 行 logo 格阵（每格一个线稿 logo 位：几何图形组合 + mono 假名，等间距无线框）。
- **坐标**：导语 y160；格阵 x100–1820、y240–880，单元 ≈230×140。
- **铁律**：低频页型；**logo 全部自编虚构**（几何字母标），禁描真实商标；格阵是"云"不是主角，密度本身即信息。
- **样本**：参考《产品手册》伙伴墙页结构。

### B45 · 双金字塔对照映射（层级体系对译）
- **用途**：两套层级体系的对照与映射（两套会员/职级/权限体系）。

- **样本**：参考《产品手册》《工商协同》体系对照页结构。

## C. 粒子海报页

### C0 · 封面（每份 deck 第 1 页，必需）
- **用途**：封面落版。
- **结构**：超大标题（思源宋体 Medium 76–96px 或文楷大字，居中或偏左 x300）+ 大留白（**>60%**）+ mono 元数据块（AUTHOR / DATE / VERSION / KEYWORDS，13px 字距 .3em，置左下或右下）+ 可选一处极细线稿小图形（≤15% 面积）。
- **纪律**：无 FIG 图题、无 caption、无第二信息层；doc 角注与 folio 保留。
- **样本**：trace/video/frames/shot-01 可作气质参照（封面形态自由）。

### C1 · 粒子主角 + 对照提问
- **用途**：概念隐喻页（黑匣子=未知），情绪转折。
- **结构**：canvas 极密粒子方块居中（260–280px，网格点阵 + 边缘概率镂空毛糙 + 四边外逸散粒）+ 顶部 DOM 对照行（"A→找 B ｜ C→？"，思源宋体 Medium 44px 问号）+ SVG 制图包装（虚线构造框、四角十字刻度、竖排尺寸标注、hatch 剖面影）；方块上纸色反色刻字。
- **坐标**：主角中心 (960,480–530)；对照行 y≈268；caption bottom 108。
- **样本**：shot-07（黑匣子）。

### C2 · 金句页
- **用途**：全 deck ≤3 处的情绪高点，一句话收场或转场。
- **结构**：极简——粒子氛围（dust ≤4 带，alpha ≤.18，避开中央与 caption 区）+ 可选小主角图形 + mono 小标（字距 .5em）+ caption 即金句（36px）。
- **纪律**：无 FIG 图题、无卡片、无第二信息层。
- **样本**：shot-19（它不会喊疼）。

### C3 · 粒子大字尾卡（可选形态，非默认）
- **用途**：收尾落版 / 下集预告——**尾卡形态自由，粒子大字只是其中一种；默认追求素描感极简 Outro（C4）**。
- **结构**：`PART.textPoints` 离屏采样大字（衬线 Bold 240px）→ ASCII 字符（0/1/*/-/.）或点云重绘；字冠 -30° 素描排线带（越上越淡）；SVG 套准十字、基线虚线、竖排尺寸标注；下方 mono EN 一行（字距 .42em + text-indent 补偿居中）+ 中文预告一行（300/24px）。
- **例外**：尾卡无 caption，以 FIG 图注 + 预告收尾。
- **样本**：shot-20（TRACE 落版）。

### C4 · 极简 Outro（每份 deck 最后一页，必需默认）
- **用途**：收尾——一句 CTA 或致谢，素描感、简约是目标；**不强制举例、不堆第二信息层**。
- **结构**：一句大字（衬线气质族：思源宋体 Medium 60–76px 或文楷 56–72px，居中）+ mono 署名行（13px 字距 .3em）+ 可选一处极细装饰（十字准星/短横/小圆）；留白 **>60%**。
- **纪律**：无 FIG、无卡片、无 caption（大字本身即结论）；doc 角注与 folio 保留。

### C5 · 目录导航页（Context 页主力）
- **用途**：Slide 2 目录/导航；长 deck 内可复用为章节索引（当前章高亮）。
- **结构**：N 个 Part 条目纵列（mono 大号序号 01/02/03 + 中文章题 400/30px + mono EN 副题 + 一行 300/17px 内容预告），行间 0.6px 分隔线；当前章用墨色实心序号圆/加粗高亮，其余 opacity .45；右侧或底部可放一处极细线稿小图形（≤15%）。
- **坐标**：条目区 x300–1500、y240–880；行高 110–130。
- **纪律**：条目 3–6 个；无 FIG；留白 >50%；高亮只一处。
- **样本**：参考《磐石 1.0》《P10》目录页结构。

### C6 · 章节隔页（纸底呼吸页主力）
- **用途**：章节转场——节奏策略的呼吸页（替代暗色 Impact 页）：让视线休息、宣告新章节。
- **结构**：超大章节编号（mono/衬线 200–320px，可描边空心或淡墨 opacity .18–.3 压底）+ 章节名（衬线气质族 56–76px）+ 一行 mono 章节导语（字距 .3em）；可选一处十字准星/短横装饰；留白 **>60%**。
- **纪律**：无 FIG、无 caption、无卡片；元素 ≤4 个；与 B40 竖排章节轨二选一。
- **样本**：参考《太和物联企业介绍》章节隔页结构。

### C7 · 联络尾页（商务收尾，可选）
- **用途**：商务 deck 收尾——联系方式与地址（比 C4 信息密度高的收口形态）。
- **结构**：左块地图线稿（简化街区/路网贝塞尔 + 定位钉，w≈850）+ 下方三行联系文字（300/18px）；右块名片卡（双线框：mono 姓名职务 + 电话邮箱行 + 可选线稿二维码位——方块矩阵暗示）；双块约 6:4。
- **坐标**：左块 x100–950、y180–820；右卡 x1100–1720、y200–860。
- **纪律**：可选形态，不替代 C4 的默认地位；人名电话全部自编；二维码位只做矩阵暗示，不画真码。
- **样本**：参考《产品手册》《工商协同》联络页结构。

## D. UI 写实页

### D1 · 后台界面 mock
- **用途**：展示产品后台（列表、筛选、下钻），证明"这东西真实存在"。
- **结构**：整版 DOM 线框界面（外框 inset≈100–160）：顶部 mono 筛选 chips + 按钮；左表格（5 列 grid，mono 13px 数据行，**三态墨点状态列**：空心/半填/全填，选中行 outline + SELECTED 角标浮签）；右栏树形过程日志（缩进 26px、节点 tag、✓/✕ 耗时、未执行行 opacity .35，错误节点 outline + 下方虚线 IO 详情盒）；JS 量 DOM 坐标画 SVG 直角肘形连接线（选中行→错误节点）。
- **纪律**：数据全部自行编造（应用名、输入输出、耗时），不用真实业务数据；字号可到 11.5–13px（全套特例）；无 FIG 图题。
- **样本**：shot-18（Trace 后台）。

### D2 · 图标六宫格（表达组件兜底）
- **用途**：3–6 个并列概念的最简陈列——**兜底页型**：当内容抽象到画不出关系图、又不够拆页时用。
- **结构**：2×3 或 2×2 网格，每格一枚 FontAwesome 图标（墨色、48–64px）或自绘细线小图标 + 中文小标题（400/22px）+ 两行说明（300/17px）；格间无框，靠间距分组。
- **坐标**：网格 x300–1620、y280–800，格 ≈420×240。
- **铁律**：能用自由 SVG 关系图就不用它（components.md 优先级末位）；每 deck ≤1 页；图标全墨色无动效。
- **样本**：参考《磐石 1.0》特性六宫格页结构。

### D3 · 手机多屏画廊（移动端连续流）
- **用途**：展示移动端产品的连续操作流或多个功能面——D1 的复数形态。
- **结构**：3–4 张手机线框（圆角机身轮廓 1.2px + 内部界面线稿：状态栏、列表行、按钮暗示）等宽横排，屏间细线开放箭头表操作流向；每屏正下方 mono 小标签（步骤名/功能名）。
- **坐标**：4 屏各 280×600 at x220/x640/x1060/x1480、y220；标签行 y860。
- **铁律**：屏内界面是"线稿暗示"（行块+圆点），不画写实 UI；界面数据全部自编；>4 屏拆页或改 D1 单屏深挖。
- **样本**：参考《产品手册》多屏展示页结构。
