# 纸墨线稿 · 自检清单

> 每页生成后、整份 deck 交付前各过一遍。P0 = 不通过就必须改；P1 = 强烈建议；P2 = 打磨项。
> **先跑机检闸门**：`scripts/shot-lint.py <deck目录>`（覆盖 P0 中可机检项），FAIL 清零后再截图目检。

## P0 · 硬伤（违反即返工）

- [ ] 无彩色：整页只有墨 `#191917` 及其透明度阶梯（`?cool` 主题允许蓝图青一处）。grep 检查 hex/rgb 色值。
- [ ] 无整页深色底：stage/页面背景必须是纸底 `#DFE0D9`（或其近色），墨 `#191917` 只做线条与文字、不当页面底色。
- [ ] 无渐变、无彩色色块；面板填充只有 `rgba(255,255,255,.22)`。阴影只用 `--shadow-soft`（卡片/面板标配，零偏移/墨色 2%/模糊 ≤6px）或 `--shadow-specimen`（标本贴纸，≤2px 硬偏移/墨色 4%/零模糊），**同层级不叠影**；禁彩色阴影。
- [ ] Font Mixing 不串岗：标题/金句/大字=衬线气质族（思源宋体 Medium/文楷大字）、正文/数据/UI/标签=无衬线族（思源黑体/Courier Prime）、手写=文楷。中文长句/大字不落 mono（mono EN+中文短注混排可接受）。
- [ ] UI 组件边框（卡片/面板/气泡/按钮/chip/表格行/筛选框）一律 **1px**，深浅靠颜色阶梯；SVG 图形主轮廓 1.2–1.4px；≥2px 的粗线不超过一处（✓/✗ 等符号笔触不计）。
- [ ] 三件套齐全：左上 `.doc.tl` 两行角注、底部 `.caption` 一句结论、`.folio` 页码署名（`?ppt` 打开时可见）。
- [ ] caption 是底部居中一句话（思源黑体 400 / 33–34px / bottom 100–126），陈述句、句号收尾，没有被内容压住。
- [ ] 一页一个主角：没有两个图形抢视线；**无同构矩形阵列**（同款框/同款图元重复 ≥3 且充当主体图形即返工；辅形态小节点链除外）；内容不越安全区（左右 150–220，纵向 y170–880）。
- [ ] 构图平衡：视觉重心落在中轴 x960 ±10% 内或左右明确配平；内容主体带 y260–840，不悬浮在上半页。
- [ ] 一页一核心论点；辅助元素视觉面积 ≤25%。
- [ ] 封面（第 1 页）与 Outro（最后页）存在且合规：超大标题/一句 CTA + mono 元数据或署名，留白 >60%，无第二信息层。
- [ ] FontAwesome 图标全墨色无动效；ECharts 已去色改造（墨色色板、细轴线、无阴影渐变）。
- [ ] `stageFit()` 已调用；窗口缩放时舞台等比居中不破版。
- [ ] UI/数据页的数据全部自编，无真实业务数据、无真实人名。
- [ ] 间距网格：所有 padding/margin/gap 落在 4pt 倍数（design-tokens §4.7 档位表）；无非合规值（15/6.5/26/14/7 等）。刻度齿/节点半径/形态尺寸除外。
- [ ] 对齐纪律（design-tokens §4.8 三律）：① 结构同类元素共线——同信息柱左边缘齐、同组图表纵轴/底部基线/标题缩进齐、附属标注锚定所属对象不贴固定件；② 孤立主图元按视觉配平（重心回中轴 x960±10%）；③ 平移有对齐目标→位移可脱离网格（算差值），无目标→位移必落网格。禁止 case-by-case 凭感觉挪。

## P1 · 风格一致性

- [ ] 双线卡框规约：外框 **1px**（UI 边框）+ 内缩 4–5px 的 0.6px@.35。
- [ ] 工程制图页有 `FIG. NN` 图题（mono 15px 字距 .3em + 0.6px 短横）；叙事页/UI 页可免。
- [ ] 字距纪律：mono 英文 uppercase + letter-spacing .22–.3em；居中 mono 用 text-indent 补偿。
- [ ] 字号阶梯：caption 33–34 → 卡题 24–26 → 正文 18–22 → mono 注记 12–16；没有倒挂。
- [ ] 16px 以下小字没有用 300 字重（太细不可读）。
- [ ] 视觉平衡：内容 ≈65% + 视觉元素 ≈35%；噪点 alpha 在 0.05–0.08。
- [ ] 微型 mono 档案字（边缘注释块/底部刻度排）每页 ≤2 处。
- [ ] 手工质地（木刻粗线/压印放射线/字符图形）每页至多一种，粗墨线 ≤1 处。
- [ ] 粒子只出现在粒子海报页或"崩解/缺失"语义处；dust alpha ≤ .15 且避开文字。
- [ ] 手绘批注（椭圆圈/文楷）全页 ≤1 处、全 deck ≤3 处。
- [ ] 箭头是细线开放箭头，没有实心三角。

## P2 · 整 deck 节奏

- [ ] 大字页（思源宋体 Medium 60px+）≤3 页；金句页 ≤3 页；两种之和不过半。
- [ ] 节奏策略：整 deck 全部纸底，每 3–4 张信息硬页有 1 张纸底呼吸页（章节隔页/金句页/粒子海报页），无连续 4 张以上信息硬页。
- [ ] 版式不三连：连续 3 页不用同一种版式（layouts.md 编号）。
- [ ] 叙事弧完整：封面（C0）→ Context → 主体 → 转折 → Outro（C4 默认 / C3 可选）；Outro 留白 >60%、不堆例子。
- [ ] 画板模式 `index.html` 与全屏模式 `deck.html` 的 SHOTS 配置一致（页数、编号、标题）。
- [ ] `deck.html` 全屏翻页：←→↑↓、空格、滑动都生效；页脚页码只在全屏模式出现。
- [ ] 每页 `<title>` 与实际内容一致；folio 编号与实际页序一致。

## 目检顺序（截图后按这个顺序看）

1. 远观：主角是否一眼可见、留白是否够（内容占 40–70%）。
2. 中距：层级是否清楚（图题 → 主角 → 标注 → caption）。
3. 近看：线宽是否统一档、字距是否舒服、对齐是否沿构造线。
4. 对比样本：和 `trace/video/frames/` 同类型页并排放，像是同一支笔画出来的才算过。
