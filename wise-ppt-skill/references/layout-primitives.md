# 排版原语（Layout Primitives）

> **本文档教"怎么排"，不是"选哪个"。** layouts.md 是版式成品目录（59 个样本），本文档是版式背后的**空间语法**——把 59 个版式反向抽象成 12 个可组合的排版原语。学会原语后，AI 能为任何内容推导出合理布局，不被 59 个成品束缚。

## 为什么需要原语

现有体系是"查表套模板"：AI 把内容归类到 layouts.md 的 MECE 族 → 选版式号 → 套坐标骨架。这有两个死穴：

1. **内容形状不在 59 版式里时，只会降级**（塞进六宫格），不会创造。
2. **版式知识被封印在成品坐标里**，AI 不懂"为什么这样排"，只懂"照着抄"。

原语解决这两个问题：它提取版式背后的**空间结构规律**，让 AI 从"挑成品"升级到"理解内容关系 → 选原语组合 → 自己生成布局"。59 个版式从"必须选一个的货架"变成"原语实例库 + 灵感参考"。

---

## 第一步：识别内容的"关系形状"

选原语前，先问：**这页信息之间的关系是什么？**（不是"这是什么主题"，而是"元素之间怎么连接"）

| 关系形状 | 典型信号 | 对应主原语 |
|---|---|---|
| **二选一 / 两体系对照** | "A vs B"、"旧 vs 新"、"主张 × 证据" | 中轴对分 |
| **N 个同级并列** | 无先后、无层级、无中心的 N 个要点/数字 | N 列均分 |
| **单向有顺序** | "A→B→C→D"、步骤链、版本演进 | 线性序列 |
| **两条线逐点对比** | "因→策逐条对答"、"前后态逐环节对照" | 双轨平行 |
| **一个核心被多维环绕** | "一物展开 N 维"、"单对象全方位注解" | 中心辐射 |
| **层层包裹 / 粒度递进** | "包含关系"、"防御圈层"、"由近及远" | 同心嵌套 |
| **走完一圈回到起点** | "闭环流程"、"持续迭代"、"PDCA" | 闭环环 |
| **双维度交叉定位** | "阶段 × 维度"、"时间 × 工作流" | 矩阵网格 |
| **从多到少单向收口** | "漏斗"、"筛选收敛"、"层层过滤" | 收敛三角 |
| **平台分几层** | "技术架构"、"自下而上支撑" | 横向分层带 |
| **主体 + 周边标注** | "立绘引注"、"证据批注"、"节点连接" | 标本钉引线 |
| **主叙事 + 底部总账** | "上方讲细节，底部一锤定音" | 底部横带（辅助原语） |

> **关键**：一页内容往往不只有一个关系形状——多数页是 2-3 个原语叠加。先定 1 个主原语（承载核心叙事），再叠 1-2 个辅助原语（增厚信息或收束结论）。

## 12 个排版原语

### P1 · 中轴对分（Bilateral Split）

**空间结构**：一条竖直中线把画面切成左右两半，两半内部结构同构、左右镜像。中线即"对位轴"，常带刻度齿或留 VS 缺口。

**实例版式**：B4 对比双面板 / B5 分水岭双栏 / B45 双金字塔对照 / C7 联络尾页

**适用内容**：两方对立、两套体系对照、主张×证据并置——任何"二选一"或"二体系对译"。

**与其他原语的区别**：中轴对分是"半镜像"（左右各一套完整体系），双轨平行（P4）是"列对位"（两条链逐站对照）。前者强调"两个世界的对立"，后者强调"逐点差异"。

**组合性**：常与 N 列均分叠加（每半内再切列）；与底部横带叠加做总账；中部可落桥接符（VS 徽章/中央箭头）。

---

### P2 · N 列均分（N-Column Grid）

**空间结构**：N 个等宽单元沿水平方向均分画面（N=2–5），单元间靠细竖线或纯间距分隔，无外框，单元内自由排版。

**实例版式**：B43 KPI 大数字横带 / B21 痛点→解法→成效三栏 / B41 分栏清单柱 / B36 条文陈列页 / D2 图标六宫格（2D 版）

**适用内容**：并列要点、N 个同级数字、N 个并列角色——无流程方向、无优先级、无中心。

**组合性**：最高频基元。与线性序列叠加=流程链；与中轴对分叠加=字段级对照；与底部横带叠加=数据压脚。

> **与 CSS grid 的区别**：N 列均分不是"画格子"——单元间无外框、无线宽粗细变化，靠**间距和留白**分隔，视觉上是一排"呼吸的单元"而非"表格"。这是它比 AI 默认的 grid 布局高级的地方。

---

### P3 · 线性序列（Linear Sequence）

**空间结构**：N 个节点挂在一条共享基线（横轴或竖轴）上，节点间用细线开放箭头串联，基线常带 mono 刻度齿。节点形态各异（仪器化，不同节点画不同图元）。

**实例版式**：B1 横向流水线 / B6 水平时间轴 / B3 虚实步骤串 / B35 阶梯爬升（斜轴变体）

**适用内容**：单向步骤链、时间演进、过程机制——A→B→C→D 有明确方向。

**组合性**：与 N 列均分同构（节点即列）；与双轨平行叠加=双链对比；与闭环弧叠加=闭环；与垂挂引线叠加=证据画廊。

**关键手法**：节点不要同构（不是 4 个一样的方框排队）——每个节点根据它在流程里的角色画不同图元（插头/芯片/路径/闸口），这是"工程制图感"的来源。

---

### P4 · 双轨平行对位（Parallel Tracks）

**空间结构**：两条平行的线性序列上下（或左右）排开，对应站位严格同 x 对齐，站间挂对位徽章/箭头表达"逐站差异"。

**实例版式**：B29 双轨转化路径 / B27 前后对比行矩阵 / B23 双带列阵

**适用内容**：两条流程线逐站对比、因→策逐条对答、前后态同构对照——强调"列对位"而非"两半对立"。

**组合性**：= 线性序列 × 2 + 列对位线。常再叠底部横带（B27 的 KPI 带）。

> **与中轴对分的区别**（AI 最易混淆）：双轨平行是"两条链逐站对位"（每站是一对），中轴对分是"两个世界整体镜像"（左右各一套）。B27（前后对比 4 环节）是双轨，B4（大字 VS 两半）是中轴。

---

### P5 · 中心辐射（Radial Burst）

**空间结构**：一个中心节点（实心核/双圈/方框），N 条分支沿放射方向展开到外围节点，分支线端落小圆点。

**实例版式**：B10 三向放射 / B32 中心枢纽卫星 / B28 立绘环绕引注

**适用内容**：一物展开多维、单对象全方位注解、核心能力被 N 维环绕——有明确中心。

**组合性**：与同心嵌套叠加=防御圈层；外围节点可替换为标本格；分支线可替换为权重弧。

---

### P6 · 同心嵌套（Concentric Nest）

**空间结构**：3–4 层同心方框/圆环，由内向外线型渐虚（实线→虚线→疏虚），中心为最细粒度/主体。构造十字线超出最外框、四角套准标记不擦除。

**实例版式**：B16 嵌套变焦框 / B13 同心防线 / B12 循环圆环（单环变体）

**适用内容**：包裹/防御关系、观察粒度逐层拉远、粒度递进——语义是"包含"或"层级包裹"。

**组合性**：与中心辐射叠加=圈层防御；与右侧标签栏 + 肘形引线叠加=粒度标注。

---

### P7 · 闭环环（Closed Loop）

**空间结构**：一个圆环（或矩形环）作主轨，N 段顺时针/逆时针弧箭头首尾相接，节点落环上，无起点无终点。

**实例版式**：B12 循环圆环 / B17 蛇形回环（环的拉直变体）/ B31 旅程曲线（环+起伏线）

**适用内容**：闭环流程、持续迭代、回归闭环——"走完一圈回到起点"。

**组合性**：常与四角外围卡 + 引线叠加；与线性序列叠加=蛇形回环；与贝塞尔起伏线叠加=旅程地图。

**变体**：当圆环装不下节点（>6 步）或太抽象时，把环"拉直"成上下两排折返的蛇形（B17）——本质仍是闭环，只是视觉上展开。

---

### P8 · 矩阵网格（Matrix Grid）

**空间结构**：行×列正交切成单元格，行/列各有标签栏（左侧竖栏 + 顶部尺），格内同构小字段，行间列间细线贯通。

**实例版式**：B18 链阵复合 / B7 坐标轴象限（2×2 轴切变体）/ B24 多泳道路线图 / B26 左图右 2×2 数据格 / B33 图表联排墙

**适用内容**：N 阶段 × M 维度、两维四分定义页、时间 × 工作流——双维度交叉定位。

**组合性**：B18 = 线性序列（顶链）+ 矩阵网格（中）+ 底部横带（chevron）；B7 = 十字轴切 + 2×2 网格；B24 = 线性时间轴 + 多行横带。

> **与 N 列均分的区别**：矩阵网格是"二维"（行×列都有标签），N 列均分是"一维"（只有列，无行标签）。矩阵的信息密度更高，但也更容易变成"同构表格"——必须有行/列标签栏来锚定语义。

---

### P9 · 收敛三角（Convergent Triangle）

**空间结构**：一个倒三角（顶宽底尖），两侧边连续收为塔尖，横向分隔线切层，层中央层名、左右引线出数量/字段。禁平底（必须收尖）。

**实例版式**：B11 漏斗 / B45 双金字塔（正三角成对变体）/ B38 环形进度环（收敛的低频替代）

**适用内容**：数量级递减、筛选收敛、层级体系——"从多到少"的单向收口。

**组合性**：与右侧规格单卡叠加（漏斗 + 标本面板）；与中轴对分叠加=双塔映射（B45）。

**关键约束**：连续宽度函数（`wAt(y)` 线性收窄），禁平底梯形——平底就退化成 N 列均分了，失去了"收敛"的动势。

---

### P10 · 横向分层带（Horizontal Layered Bands）

**空间结构**：3–5 条水平横带上下堆叠，左侧竖排层标签列（L1/L2…），每带内均布能力件，层间细线贯通。自下而上读=托举，自上而下读=架构。

**实例版式**：B19 分层架构堆栈 / B20 底座托举三层 / B14 甘特瀑布（时间定位变体）

**适用内容**：平台/能力分层、自下而上支撑关系、耗时分布——"分几层、每层有什么"。

**组合性**：= 横向分层带 + N 列均分（每带内）+ 左标签列。可再叠托举箭头（B20）、时间刻度尺 + 竖栅格（B14）。

---

### P11 · 标本钉引线（Pinned Specimen + Leader）

**空间结构**：一个主体（立绘/DOM 面板/场景）居中或偏置，四周 N 个双圈锚点用肘形细引线（先横后竖，单调不交叉）连到外置标注块。

**实例版式**：A1 标本卡（单点圈错）/ B28 立绘环绕引注 / B16 嵌套变焦框（引线挂标签栏）/ B15 星座映射网（弧线替引线）/ B2 权重弧线图

**适用内容**：单对象注解、证据原件批注、节点间连接——主体 + 周边标注。

**组合性**：与中心辐射叠加；引线可替换为权重弧（B2/B15）。

**关键手法**：引线是"肘形"（先横后竖，直角拐弯），不是斜线——这是工程制图的标准引线画法，比 AI 默认的"斜线连"更克制、更精密。

---

### P12 · 底部横带压脚（Basal Strip Foot）— 辅助原语

**空间结构**：画面底部一条通栏横带（KPI/口号/chevron 收束/总账），上方留给主图或主叙事，带与主区之间留呼吸缝。

**实例版式**：B43 KPI 横带（独立式）/ B27 前后对比 + KPI 带 / B18 chevron 收束条 / B26 左图右数据（右栏变体）

**适用内容**：给主叙事一个"总账"收口、数据压脚、阶段结论——上方讲细节，底部一锤定音。

**组合性**：纯辅助基元，与几乎所有叙事原语可叠。最常叠在双轨平行、矩阵网格、标本钉之下。

## 原语组合规则（版式 = 原语叠加）

### 组合 1：B27 前后对比 = 双轨平行 + 底部横带
上下两行各 4 列同构对位（双轨平行），底部通栏 KPI 带（底部横带）收总账。"叙事原语 + 数据压脚"的典型叠加。

### 组合 2：B18 链阵复合 = 线性序列 + 矩阵网格 + 底部横带（三原语复合）
顶部阶段链（线性序列）+ 中部维度矩阵（矩阵网格）+ 底部 chevron 收束（底部横带）。信息密度最高的页型，三原语正交叠加。

### 组合 3：B17 蛇形回环 = 线性序列 × 2 + 闭环弧
上下两排反向线性序列，两端大弧接成环。当 B1 装不下（>4 步）、B12 圆环又太抽象时的折中方案。

### 组合 4：B13 同心防线 = 同心嵌套 + 中心辐射
三同心环（同心嵌套）+ 环外径向引线（中心辐射的外引方向）。"包裹语义 + 全周注解"的复合。

### 组合 5：B16 嵌套变焦框 = 同心嵌套 + 标本钉引线 + 左标签栏
四层同心方框（同心嵌套）+ 每层肘形引线到右侧标签栏（标本钉）。"包含 + 标注"双语义。

## 怎么用原语生成布局（AI 决策流程）

1. **识别内容的关系形状**：这页信息是"对立""序列""嵌套""辐射"还是"收敛"？用上方"关系形状"表定主原语。
2. **定 1 个主原语**：承载核心叙事的空间结构（如"前后对比"→双轨平行）。
3. **叠 1-2 个辅助原语**：需要总账？叠底部横带。需要标注？叠标本钉。需要收口？叠收敛三角。
4. **参考版式成品**：查 layouts.md / gallery 找用同样原语组合的版式样本，借鉴坐标和图元画法。
5. **生成坐标布局**：基于原语的空间规则，自己推导元素在 1920×1080 里的位置——不必照抄成品坐标，成品只是参考。

> **超出框架的授权**：如果内容的关系形状不在 12 原语里，或需要原语的新组合方式，**AI 有权发明新版式**——只要遵守 design-tokens 的空间纪律（可用空间居中、主角占比、线宽档位）。layouts.md 的 59 版式是"已知解"，不是"允许解的全集"。

## 特例版式归属

以下版式未在上文逐一列出编号，但它们的空间结构都归入已有原语（只是内容语义特殊或频率低）：

| 版式 | 归属原语 | 说明 |
|---|---|---|
| A2 场景画 / A3 文献摘引 | 标本钉引线 / 单主角留白 | 单主体 + 标注，或纯证据陈列 |
| B8 环节树+规格单 | 中轴对分（双区变体） | 左结构右字段，不对称双区 |
| B9 汇聚流 | 中心辐射（收敛方向） | 多源向中心的逆向辐射 |
| B22 左策略右证据墙 | 中轴对分 / N 列均分 | 不对称双区 + 右侧网格 |
| B25 时间轴垂挂画廊 | 线性序列 + 标本钉 | 轴上节点垂挂证据卡 |
| B30 排行柱图 | N 列均分（柱状变体）+ 标本钉 | 降序柱 + Top3 垂挂标本 |
| B34 顶图卡列阵 / B39 证书墙 / B44 Logo 墙 | N 列均分（卡片/缩略网格） | 并列陈列，无关系 |
| B37 地理气泡地图 | 标本钉引线（地图变体）+ 底部横带 | 地图主体 + 气泡标注 + KPI 带 |
| B40 竖排章节轨 | 页级铬件（非独立版式） | 全 deck 统一用或不用 |
| B42 蜿蜒道路时间轴 | 线性序列（S 形变体） | 长跨度的曲线序列 |
| C0-C6 封面/粒子/金句/Outro/目录/隔页 | 单主角留白（骨架页特例） | 每 deck 必备的骨架页，留白 >60% |
| D1 后台界面 mock / D3 手机多屏 | UI 写实（特殊类别） | 整版 DOM 线框，不走原语体系 |

> **骨架页（C0-C6）和 UI 写实页（D1-D3）是特殊类别**：它们有固定结构（封面必有标题+落版、Outro 必极简、UI mock 必整版线框），不走原语组合的通用流程，直接查 layouts.md 对应条目套用。原语体系主要服务于**信息内容页**（B 族 + A 族）。
