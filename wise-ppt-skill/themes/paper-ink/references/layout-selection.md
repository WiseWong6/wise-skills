# 纸墨主题与公共布局的边界

本文件不定义选版规则。Gallery 是公共布局能力，权威目录与使用规则分别位于：

- `capabilities/layouts/gallery-manifest.json`
- `capabilities/references/layout-gallery.md`

Core 先决定页面关系、空间需求、区域和阅读顺序，再由公共能力层判断是否使用既有 recipe、按既有结构重新选择组件，或建立新的页面结构。`paper-ink` 不参与这项判断，也不维护第二份目录、候选分类或容量规则。

## 主题只处理视觉呈现

公共能力层确定页面结构后，纸墨主题只负责以下事项：

- 把字体角色、颜色、线宽、间距与纸面质感映射到主题 token；
- 通过 `theme_adapter_id` 适配已选 renderer，不改变事实、区域、顺序或主次；
- 保持 1920×1080 画布、安全区、溢出和可读性要求；
- 让 Gallery 样张、正式 Deck 和 PDF 使用同一套视觉资产。

主题不得因为视觉偏好增删 slot、改变 reading order、替换组件来源或改写公共 recipe。结构需要变化时，回到 Core 与公共能力层重新决策。

## 纸墨视觉落位

- 中心型结构按几何中心落位；非对称分栏、证据墙、时间轴、UI、流程和架构页沿结构线对齐。
- 矩阵与同级并列可以使用网格，但网格不是默认骨架；列数来自已经确定的结构合同。
- 页面恰好保留一个主视觉角色，支持组件必须服务同一 takeaway。
- 信息较多时仍使用正式字阶、清晰分组与安全区；出现溢出时由 Core 调整媒介、结构或页数，主题不得通过缩字或裁掉事实解决。
- Gallery 浏览壳与正式 Deck 控件使用公共 runtime 和本地语义 SVG；主题只提供纸墨色彩、线型和交互状态。
