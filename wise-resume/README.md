# Wise Resume

面向中国中文招聘的简历诊断与优化 Skill，以产品岗位为主，运营岗位可一定程度复用；也可为成形简历排版。提供两种工作方式：

- **只排版**：不改原文，套用既定版式交付 HTML；缺少简介或辅助栏目不补写。
- **诊断与优化**：先给主要问题、修改理由和关键示范，确认方向后再改全文、生成 HTML。已明确授权在现有资料内优化时，直接交完整优化稿，缺少补充信息或岗位描述也可先做通用优化；只诊断时到建议为止。

简介围绕定位、支撑和辨识度，建议三句、允许一至三句。第三句优先选大部分人不容易做到、且有助于岗位判断的真实事情，如具体开源贡献、独立开发作品或有分量的奖项；其次是用户自述的价值观、性格或有辨识度的兴趣实践，没有合适材料就少写一句。工作经历先突出有依据的贡献或实践重点，再展开行动。有真实成果时突出成果；只有参与范围和动作时也能提炼、归组和精简，不强凑结果句或等补齐数字再动笔。

改写保护事实含义，允许跨句归纳、重组和压缩，不要求保留原句。以招聘方能否更快看清定位、主要经验和本人贡献判断优化是否有效；不以改字数量或“全文改写”的自评代替。先交稿，再提少量有价值的补充问题；用户明确不补充时不重复追问。

岗位描述优先使用用户提供的材料；缺少时请用户补充，或明确目标岗位后联网查找。搜索资料注明来源，区分目标岗位要求与同类岗位参考；找不到也可先做通用诊断。

简历内容分工：基础信息用于识别和联系，简介给出快速判断，工作经历展开贡献依据，辅助内容补充独立信息。简介概括成果、经历展开证明，是层级配合，不是需要删掉的重复。

优化时默认不设技能栏，只有具体、与岗位相关、有依据且能补充独立信息的专业技能才单列。通用工具清单或泛泛的能力标签不作为优势；已经由工作经历证明的能力不重复列出，没有合适内容就删除整个栏目。仅排版时保留用户原文并另提建议。

任职内区分业务背景、可选总述、贡献要点和荣誉补充。背景、总述与荣誉不进贡献编号；并列贡献按同一标准划分，不相互包含或重叠，覆盖所选贡献的关键依据即可。不同产品的行动与数字保持原归属，团队增长不是移进背景就必须保留。

优化版基础信息只允许姓名、联系方式、已确认的当前常驻城市、本人头像，缺项省略；经历标题只含日期、公司或产品名称、职位，不附加地区，完整保持一行。用户已授权在现有材料内优化时，重新筛选所有模块，不把仅排版时保留的字段自动沿用。

诊断按基础信息、个人简介、工作经历、辅助内容逐项进行，每个模块给出具体问题、修改理由、改法和必要示范。最后复核全篇的一致性、重复、岗位重点与排版；真实性、岗位相关性和可理解性贯穿各模块，同一问题只说明一次。

## 文件与规则

主入口为仓库根目录的 `SKILL.md`。Codex 使用 `$wise-resume`，Claude Code 和 DeepSeek Harness 使用 `/wise-resume`，ZCode 从技能菜单选择 `wise-resume`，均由用户手动调用。

- 写作原则以主入口为准；具体疑点查 `references/content-methodology.md`，改写示范查 `references/examples.md`，均按需读取。
- 排版细节唯一来源是 `assets/template/DESIGN-SPEC.md`。
- 两个中性模板为 `assets/template/index.html`（多页竖版）、`portrait.html`（单页侧版），共享同目录 `assets/` 中的字体、样式、控件和分页。

以上资源路径相对于 Skill 目录。

## 先交 HTML

用户提供简历与已有岗位资料，AI 负责诊断、改写和填写模板。网页只保留两份共享代码，分别负责外观切换和 A4 分页；它们不判断内容好坏，也不自动删减文字。

复制中性模板和共享资源到交付目录，填入用户原文或确认后的文案。缺少可选信息时移除相应占位。若交付两版，放在同一目录供菜单切换，共有文字保持一致；仅交一版时移除版式选择项，避免跳转到不存在的文件。

新建默认多页竖版、纯白背景、正黑配色、霞鹜文楷；保留用户已选外观。

基础信息在页眉；多页竖版依次放简介、工作经历和辅助栏目，单页侧版左侧简介及辅助内容、右侧工作经历。教育、技能、语言、荣誉等按需复用样式，不打乱核心位置。

优化或已授权补充内容时，尽可能用已有材料中的相关贡献、判断、行动和结果减少大段空白。侧版右栏有空间就优先补回有价值的内容，避免过度精简；不靠拉大间距或字号填满，也不凑字、编造。仅排版仍保持原文。

按文案直接编辑 HTML，以 `file://` 打开，不需要服务器。核对文字完整性、本地字体与样式路径，提供绝对路径，请用户确认内容与视觉。此阶段不生成 PDF。

字体加载完成后自动分页。工作经历标题按实际文字宽度排在同一行，不再等分挤压或自动折行；侧版教育仍按三行排列。若字体加载失败、标题不能完整保持一行或文字放不下，页面保留原文并提示原因，打印按钮保持禁用；解决问题后再验收。

外观可选：思源黑体、思源宋体、霞鹜文楷；墨蓝、正黑；纯白、米白纸纹；头像与左侧装饰分别开启或关闭。交付时说明采用的外观。

多页竖版一般 1–2 页，资深且内容有价值时最多 3 页；单页侧版严格一页。放不下时先讨论取舍或改版式，不缩字、藏内容或自动删除原文。

## 确认后才出 PDF

用户确认当前 HTML 内容与视觉后，保留已选外观，通过浏览器打印保存为 PDF。打印设置：A4、100% 比例、无额外页边距、关闭浏览器页眉页脚，并启用背景图形以保留纸纹、线条和列表圆点。

核对 PDF 的页数、字体、文字完整性和阅读顺序，与已确认的网页一致。HTML 改动后重新验收再导出，未实际验证的项目如实说明。

## 交付检查

按 `references/review-checklist.md` 检查当前阶段。源码核对、内容判断与用户实际显示验收分别说明，不能把文件检查通过当作视觉已经认可。

内容复核先对照前后稿的阅读改善，再按含义逐句核对材料、逐项审查保留信息并回查诊断问题；归纳句可由多处材料共同支撑，关键词命中、未新增数字不能证明优化完成。模板的既有换行行为不作为合格依据，标题须按设计规范处理并由用户实际验收。
