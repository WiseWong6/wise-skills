# Semantic style selection

Read this file only when the user has not selected `S01`–`S11`. Choose one style; do not blend styles.

## Selection matrix

| ID | Best semantic fit | Visual intensity | Avoid when |
| --- | --- | --- | --- |
| S01 | Architecture, streets, stacked facades, blue exposure and tonal depth | medium | the source depends mainly on flowing line motion |
| S02 | Strong perspective, repeated lines, curves, cables, roads, structural rhythm | medium-high | the source is soft, quiet or materially textured rather than linear |
| S03 | Heterogeneous detail, experimental editorial energy, many distinct local textures | high | the user asks for restraint, silence or minimal color |
| S04 | Simple or isolated subject, refined material study, abundant negative space | low | the scene needs energetic movement or dense information |
| S05 | Crisp man-made geometry, grids, facades, technical drawing and one dominant interference zone | medium | the subject is mostly organic or atmospheric |
| S06 | Layered architecture, asymmetrical plates, blue tonal depth and translucent overlap | medium | the source needs near-monochrome silence |
| S07 | Fog, rain, cloud, haze, changing light or atmospheric environment | low-medium | the source has no meaningful atmosphere |
| S08 | Recognizable structure with multiple surfaces or materials; robust general-purpose choice | medium-high | a more specific atmospheric, organic or minimal cue clearly dominates |
| S09 | Organic growth, vegetation, wind, particles, soft motion and near-monochrome treatment | medium | the scene is rigidly architectural with no organic cue |
| S10 | Clear opposition between organic curves and rectilinear structure | medium-high | only one visual family is present |
| S11 | One centered or symmetric subject, quiet edges, spatial silence and restrained cyanotype | low | the scene needs dense edge-to-edge treatment |

## Decision order

1. Prefer an explicit user-selected `Sxx` over automatic selection.
2. Identify the primary semantic driver: linear motion, material layers, atmosphere, organic growth, mixed structure, or spatial silence.
3. Use composition as the tie-breaker: strong vanishing lines favor S02; centered isolation favors S11; complex surfaces favor S08.
4. Use S08 only when no more specific style clearly wins.
5. State one concrete reason tied to the source image; never claim a generic preference.

## Reference policy

Use `style-catalog.html` to show options. The images are visual documentation only and must never be added as Image 2 or style inputs to image generation.
