## 1. 色彩系统

页面壳与临时光效固定使用：

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| `paper` | `#f1efe9` | 暖纸白背景 |
| `ink` | `#1c2829` | 文字、控制与深色线 |
| `bronze` | `#7c3d28` | 品牌强调、选中态 |
| `white-model` | `#eeeae0` | 暖白诊断材质 |
| `scan-gold` | `#ffb762` | 临时边界与高光基色 |
| `halo-core` | `#ff8d3a` | 光圈核心 |
| `halo-glow` | `#ffc66f` | 柔光层 |
| `halo-disc` | `#ff9b4b` | 低透明软盘层 |
| `apex-spark` | `#ffd27d` | 仅有真实顶点语义时可用的完成火花 |

不要把这套色板强加给建筑真实材质。主体材质以 ReferenceBundle 的证据为准；暖金只存在于临时扫描边界、光头或短暂高光。

Three.js 使用 Linear-sRGB 工作空间和 sRGB 屏幕输出。颜色纹理标注 `SRGBColorSpace`，法线、粗糙度、金属度等数据纹理保持无色彩空间。自定义 Shader/RawShader 必须显式完成输出转换；使用 EffectComposer 时把 OutputPass 放在链尾。

官方参考：

- https://threejs.org/manual/en/color-management.html
- https://threejs.org/docs/pages/OutputPass.html
- https://threejs.org/docs/pages/Material.html

## 2. 光效基准与抽象边界

- 巴黎铁塔前两个基准分别提炼为 01“扫描截面经过后恢复真实材质”和 02“几何沿合法轴出现”；只复用状态语义，不复用铁塔尺寸、相机、像素位置或固定半径。
- 鸟巢第三个基准提炼为 03“光头与短尾沿真实网格拓扑传播，并同步驱动表面材质恢复”；网格、种子、可达性和路径必须来自当前主体。
- 三种能力共享 `progress=1` 的完整真实材质终态，但中段机制互斥：01 是截面，02 是裁切/显现，03 是图传播。

## 3. 公共不变量

所有模式都必须满足：

- 进度限制在 `[0,1]`，同一输入产生确定性画面。
- 切换光效只重启时间线，不改变 camera、controls target、presentation root 或 primary subject matrix。
- `progress=1` 恢复完整几何和真实材质，临时光圈、发光线、裁切、emissive 与局部光全部清零。
- `prefers-reduced-motion` 或 `reduced_motion=1` 直接进入完成态、暂停、无自转、无脉冲。
- 用户暂停冻结全部自主运动，包括 auto-rotate、damping、shader time、pulse 和局部光；用户拖拽不应被禁用。
- 主体 object-ID pass 排除地面、阴影、光效、光圈、上下文和控制栏。
- 不通过动态可见部分重新做构图 fit；始终使用完整完成态主体轮廓。
- 禁止全局曝光跳变、整画布 bloom、模型整体改金色或用相机移动制造“生长”。

## 4. 光效 01：扫描上色 `color`

### 视觉语义

保持完整暖白模型可见。扫描截面自下而上移动，经过区域恢复真实材质，未经过区域保持暖白；暖金只标记当前边界。

### 必需结构

- 一个语义光圈，由 `core / glow / soft-disc` 三层组成。
- 光圈根据当前真实截面分别计算中心、X 半径和 Z 半径；允许椭圆或超椭圆，禁止固定全包络圆环。
- 截面包络必须在所有检查点严格包含主体当前切片并保留正余量。
- 边界附近允许短暂 rim 和移动局部光；强度随进度连续变化，完成态归零。
- 光圈不做可见旋转来伪装贴合，不改变模型矩阵。

### 推荐状态

- `progress=0`：完整暖白，光圈位于最低有效截面。
- `progress≈0.5`：下部真实材质、上部暖白、当前截面暖金边界。
- `progress=1`：完整真实材质，光圈和临时光全部消失。

### 失败信号

- 光圈穿过模型或离主体过远。
- 光圈始终按完整 bounds 缩放，遇到偏心/长方形建筑失配。
- 扫描后区域仍是白模，或完成态残留金色。
- 光圈、相机或模型旋转掩盖截面错误。

## 5. 光效 02：结构生长 `build`

### 视觉语义

让几何沿经过验证的生长轴逐步出现。建筑默认以局部 Y 轴自下而上，但水平桥梁或特殊结构应在 ModelBrief 中显式定义合法轴。

### 必需结构

- 使用材质 discard 或局部裁切平面隐藏边界前方几何，不移动或缩放主体。
- 不显示 01 的外包络光圈。
- 在当前生长边界加入窄暖金带、短暂 rim 和有限范围局部光。
- 阴影、深度和双面策略应避免出现完整上部幽灵、内部大面积穿帮或错误封口。

### 推荐状态

- `progress=0`：主体几何不可见或只保留合法基座起点。
- `progress≈0.5`：仅已建造部分可见，边界窄且构图不重算。
- `progress=1`：完整真实材质，无裁切、边界光或临时局部光。

### 失败信号

- 上部完整可见，仅改变颜色。
- 中段自动放大或上移来填满画布。
- 显示与主体截面无关的大光圈。
- 完成态仍有 clipping plane、discard uniform 或临时 emissive。

## 6. 光效 03：拓扑寻光 `edge-color`

### 视觉语义

让短暖金光头和短光尾沿真实或可追溯的结构骨架传播，后方同步恢复真实材质。适用于桁架、网格、管线、壳体肋骨和明确的结构边。

### 必需结构

- 建立带稳定 feature ID 的结构图；优先作者明确的结构曲线，其次使用语义 mesh 的可见折线。
- 从合理种子点执行确定性传播；建筑通常从落地点、多支撑或连接节点启动。
- 使用同一到达场驱动表面材质恢复，避免光头与材质进度分离。
- 绘制深度测试、depthWrite=false 的窄 ribbon/line；光头明亮、光尾短且衰减。
- 严格将水平高度带、光圈、全局 rim 和移动局部光设为零。
- 对每个 required feature 记录可达性；关键结构不可达时不得交付 03。

### 推荐状态

- `progress=0`：无可见临时线，主体保持暖白。
- `progress≈0.5`：局部光头沿结构折线分支推进，短尾清晰，已到达区域恢复真实材质。
- `progress=1`：完整真实材质，可见临时线段为零。

### 失败信号

- 退化为自下而上的水平扫色带。
- 只沿外轮廓整圈发光，内部结构无传播。
- 光线穿透前景、漂浮在结构外或覆盖所有像素。
- required feature 不可达，却用全局材质混合伪装覆盖率。

## 7. 自动选型

按顺序执行：

1. 如果 required features 中存在桁架、diagrid、网壳、肋骨或结构曲线，并能建立覆盖所有关键 feature 的连通图，选择 `edge-color`。
2. 否则，如果主体具有明确分层、塔身、堆叠、桥跨装配或合法生长轴，选择 `build`。
3. 否则选择 `color`。
4. 如果 03 的 required feature reachability 未达 100%，退回 01；不要通过降低门禁强行交付。
5. 如果用户指定模式，仍先检查适配性；无法满足时解释失败信号并使用 01 作为安全默认，除非用户明确拒绝替代。

允许多个模式共享同一完整态材质和相机，但不得共享错误的视觉机制：02 不得出现 01 光圈，03 不得复用高度扫描。

## 8. 时间稳定性与深度

- 一个预览只有一个时间源和一个 animation loop owner。effect、相机自转、damping、shader 与临时光不得分别用墙钟推进。
- 进度更新使用 RAF timestamp；hidden/visible 恢复首帧只重置 baseline，不补算后台时间。
- 模式切换和 replay 先形成完整目标状态，再在同一帧提交材质、uniform、可见性、灯光和控件文案。
- 全部已选模式在隐藏 loading 前预热 shader variant；不得把首次点击时的同步编译卡顿交给用户。
- 程序噪声、法线扰动和细线需要低通、导数抗锯齿或 mipmap。随相机移动产生逐像素跳变的高频 `sin/fract` 细节不得交付。
- 透明线/overlay 使用 `depthTest=true`、`depthWrite=false` 时仍要解决共面竞争；采用几何偏移、clip-space depth bias、polygon offset 或深度预通道，不能只设 `renderOrder`。
- 布尔资源在视觉强度衰减到 0 后再关闭；在 `0.98 / 0.99 / 1` 检查亮度、主体覆盖率、阴影和轮廓连续性。

完整失败模式和连续帧验收见 [motion-stability.md](motion-stability.md)。

## 9. 性能与清理

- 将光圈层合并为固定少量 draw calls；将 edge flow 合批，不为每条边创建独立 Mesh。
- 限制 DPR，按设备能力选择阴影分辨率，不以牺牲紧凑视口可读性换桌面 bloom。
- 在 `pagehide`/unmount 中停止唯一 animation loop，取消事件和加载任务，释放 geometry、material、texture、render target、program 和 object URL。
- 使用 `renderer.info` 或 WebGL 资源计数检查重播、切换和 resize 后没有持续增长。
- 测试结束停止本轮服务器和浏览器；保留结构化报告，仅在明确授权视觉验收时保留交付截图，并清理缓存、临时依赖和失败产物。
