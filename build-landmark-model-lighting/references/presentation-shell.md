# Loading 与底部播放条

本页只约束地标预览的加载状态与底部播放控制，不统一建筑身份信息、材料、镜头、场景背景或光效实现。

## Loading

- 固定在当前 3D 视口的几何中心；使用定位与 transform 保证视口尺寸变化时仍保持中心。
- 采用暖白半透明胶囊、细边框、轻阴影、模糊背景、16px 旋转环和固定文案“正在加载 3D 模型”。
- 静态页面标记 `data-landmark-loading`；React/组件页面使用同名属性。推荐环使用 `.landmark-loading-ring`。
- 同一 3D 视口任何时刻最多保留一个可见 loading；集成画廊不得与子页面重复注入。禁止使用固定时长自动消失或未限定范围的伪元素注入 loading。
- 只有在资产下载、指纹/结构校验和真实首帧渲染全部完成后才隐藏；`[data-landmark-loading][hidden]` 的隐藏优先级必须高于展示规则。
- 失败时隐藏 loading，显示独立错误说明和可操作的重试按钮；不得无限旋转。
- 在 `form-atlas` 中，静态页面优先复用 `public/white-models/shared/presentation-shell.css`，React 页面复用 `app/globals.css`；集成画廊只注入公共展示壳。

## 底部播放条

- 固定底部居中并避开 `safe-area-inset-bottom`，标记 `data-landmark-playback`。
- 采用与 loading 一致的暖白半透明胶囊、边框、圆角、阴影和背景模糊。
- effect 选择、时间线、暂停/继续和重播属于同一控制组；桌面最小高度 54px，紧凑视口最小高度 50px。
- effect 按钮最小 `30×30px`，主播放按钮桌面推荐 `38×38px`、移动推荐 `34×34px`。
- 公共展示壳统一接管模式按钮的默认态/选中态，以及播放、暂停、重播图标；不得回退到浏览器默认按钮背景或文字字符图标。
- 光效切换和重播保留用户视角；播放条不得遮挡主体关键识别特征。

## 验收

在 `1440×900` 和 `390×844` 检查：

1. loading 首帧可见且位于当前 3D 视口中心，同一视口可见实例恰好一个。
2. ready 或 error 后可见 loading 实例为零；失败时进入可恢复错误态。
3. 播放条完整可见，按钮可点击/触摸，时间线状态与运行时一致。
4. loading、播放条和主体无重叠溢出；集成画廊切换无旧 iframe/WebGL 残影；控制台与资源请求无错误。

材料取证、动画时长和具体光效仍由主工作流与项目 ModelBrief 决定，不属于本展示壳的视觉硬约束。
